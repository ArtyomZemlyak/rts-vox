# 12 — Реестр решений

По строке на решение: **что решено** и где лежит разбор. Обоснования,
рассмотренные варианты, источники, цена и поправки — в
`analysis/10-decisions-full.md` под тем же номером.

Решение не редактируется. Оно заменяется новым ADR со ссылкой
«заменяет ADR-NNN».

## Платформа и слои

| ADR | Решено |
|---|---|
| 001 | Rust, десктоп, open source |
| 002 | Bevy `=0.19.1` — каркас **только** рендер-слоя; wgpu 29.0.3 |
| 003 | `sim-core` — отдельный крейт, о движке не знает |
| 009 | ECS только в рендере; симуляция на плотных SoA-массивах |
| 010 | Тесты — основной интерфейс агента; реплей как оракул |
| 012 | Цикл итерации (время сборки, headless-прогон) — инженерное требование |

## Детерминизм

| ADR | Решено |
|---|---|
| 004 | Детерминизм обязателен; вся математика симуляции — `Fx`, i64 Q32.32 |
| 026 | Шейдеры: пин бэкенда Vulkan, `zero_initialize_workgroup_memory`, самодостаточный WGSL. `SHADER_INT64` на пине есть, но непригоден (naga #7109, #5276) |

## Мир

| ADR | Решено |
|---|---|
| 005 | Разрушаемость двухуровневая: synced воксели / unsynced обломки |
| 013 | Копка — экономика, а не событие: правки вокселей идут каждый тик, с потолком и очередью |
| 015 | Целостность породы не считается; отделившийся кусок схлопывается. **Материя при этом возвращается в землю** (уточнено ADR-023) |
| 019 | Многомасштабность: дискретный набор масштабов, вся математика в мировых единицах |
| 024 | Хранение: чанк 32³ row-packed, горячий слой распакован; мешинг берёт свои срезы |

## Юниты и бой

| ADR | Решено |
|---|---|
| 016 | Юнит — воксельный том с ядром; скалярного HP нет, урон позиционный |
| 017 | Реклейм — та же операция, что копка |
| 020 | Сложная форма — составное тело из томов; полигональных мешей в симуляции нет |

## Экономика

| ADR | Решено |
|---|---|
| 021 | Контейнеры физичны и уязвимы, содержимое — количество, не кубики |
| 022 | Материя — воксели; энергия — не воксели и не сохраняется |
| 023 | Перечень стоков материи; исчезновение материи запрещено везде |

## Навигация

| ADR | Решено |
|---|---|
| 007 | Свой flow field поверх иерархии, не сторонний крейт |
| 014 | Навигация по поверхностному многообразию проходимых вокселей |

## Рендер

| ADR | Решено |
|---|---|
| 006 | Рендер поэтапно: полигональный меш, при провале бюджета — марш луча |
| 011 | Лестница деградации рендера (порядок ступеней уточняется, см. `04-world.md`) |
| 018 | Гибрид: греди-меши для мира, марш луча для тел |
| 025 | Симуляция остаётся на CPU; GPU — рендер и unsynced |
