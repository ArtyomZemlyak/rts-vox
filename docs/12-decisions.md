# 12 — Реестр решений

По строке на решение: **что решено** и где лежит разбор. Обоснования,
рассмотренные варианты, источники, цена и поправки — в
`analysis/10-decisions-full.md` под тем же номером.

Решение не редактируется. Оно заменяется новым ADR со ссылкой
«заменяет ADR-NNN».

## Платформа и слои

| ADR | Решено |
|---|---|
| 001 | Rust, десктоп, open source |
| 002 | Bevy `=0.19.1` — каркас **только** рендер-слоя; wgpu 29.0.3 |
| 003 | `sim-core` — отдельный крейт, о движке не знает |
| 009 | ECS только в рендере; симуляция на плотных SoA-массивах |
| 048 | Окончательный список фаз тика — 15 фаз, включая `fluids` и `bodies` заглушками |
| 010 | Тесты — основной интерфейс агента; реплей как оракул |
| 012 | Цикл итерации (время сборки, headless-прогон) — инженерное требование |

## Детерминизм

| ADR | Решено |
|---|---|
| 004 | Детерминизм обязателен; вся математика симуляции — `Fx`, i64 Q32.32 |
| 026 | Шейдеры: пин бэкенда Vulkan, `zero_initialize_workgroup_memory`, самодостаточный WGSL. `SHADER_INT64` на пине есть, но непригоден |

## Мир

| ADR | Решено |
|---|---|
| 005 | Разрушаемость двухуровневая: synced воксели / unsynced **косметика** (пыль, искры). Обломки юнитов и построек — synced тела |
| 013 | Копка — экономика, а не событие: правки вокселей идут каждый тик, с потолком и очередью |
| 044 | Реклейм снимает воксели обломка группами |
| 045 | Потолок правок считает **затронутые воксели**, в любом масштабе; у боя свой суб-пул |
| 015 | Порода не имеет модели напряжений, но **отделение детектируется**: подкоп обязан работать. Материя схлопнувшегося куска возвращается в землю |
| 055 | Потеря опоры — каскад из трёх фильтров; граф компонент чанков вместо полнообъёмных меток |
| 019 | Многомасштабность: дискретный набор масштабов, вся математика в мировых единицах |
| 024 | Хранение: чанк 32³ row-packed, горячий слой распакован; мешинг берёт свои срезы |
| 027 | Частота тика — 30 Гц |
| 030 | Форма забоя произвольная и различает фракции; рваная геометрия — базовый случай |
| 032 | Порядок правок — round-robin со сдвигом курсора; приоритетов нет |
| 033 | Материал, внешний вид и динамическое состояние — три разные вещи |
| 034 | Границы мира — неразрушимая рамка |
| 035 | Каждый выстрел взаимодействует с геометрией; степень разрушения рельефа балансится |
| 042 | Вода «ищет свой уровень»; морские юниты есть |
| 049 | Воды в воксельной сетке нет: водоём — контейнер с объёмом и производным уровнем |
| 029 | Туман скрывает и рельеф; у каждого игрока своя память о мире, поиск пути идёт по ней |

## Юниты и бой

| ADR | Решено |
|---|---|
| 016 | Юнит — воксельный том с ядром; скалярного HP нет, урон позиционный |
| 017 | Реклейм — та же операция, что копка |
| 020 | Сложная форма — составное тело из томов; полигональных мешей в симуляции нет |
| 036 | Юнит на исчезнувшей опоре падает; сильный удар убивает |
| 037 | Падающие тела давят юнитов и постройки |
| 050 | Столкновения тел: XZ-столбцы и редукция вместо широкой фазы; падение строго вертикальное |
| 040 | Щит физически останавливает снаряды; подкоп под него работает |

## Экономика

| ADR | Решено |
|---|---|
| 021 | Контейнеры физичны и уязвимы, содержимое — количество, не кубики |
| 022 | Материя видна в мире как воксели, но **в контейнере она количество, а не кубики**; энергия — не воксели и не сохраняется |
| 023 | ~~Перечень стоков материи~~ — **заменён ADR-046** |
| 046 | Перечень стоков — один, в `07-economy.md`. Броня в контейнере `damage`, не сток. Жидкости вне инварианта |
| 047 | Нейтральный владелец: земля, порода, обломки, вода. Свой пул правок, своя позиция в round-robin |
| 031 | Воксель резервируется за копателем |
| 038 | Потолки правок подушевые, а не глобальные |
| 043 | Общий потолок материи у игрока, поднимаемый складами |

## Навигация

| ADR | Решено |
|---|---|
| 007 | Свой flow field поверх иерархии, не сторонний крейт |
| 014 | Навигация по графу проходимых вокселей. Предпосылка «юниты не летают» **снята** (ADR-039, ADR-041) |
| 029 | Туман скрывает рельеф; поиск пути идёт по памяти игрока |
| 053 | Навигация форкается только на уровне связности: 134 КиБ на группу, утечка ≤ диаметра сектора |
| 054 | Инкрементального эйконала нет: сектор пересчитывается целиком |
| 039 | Юниты ходят внутри туннелей; мир объёмный |
| 041 | Авиация есть; навигация многослойная — земля, воздух, вода |

| 011 | Лестница деградации рендера (порядок уточняется; **ступень 4 недоступна на пине** — процедурные AABB только с wgpu 30) |
