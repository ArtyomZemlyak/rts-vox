# Повторная проверка сценариев: управление задачей — 16.10.2026

База main17f6660, продолжение [308](308-mission-clarity-and-critical-guns.md),
ADR-733. Повторно проверяются управление, условия потери участников и
возможность пройти операции другой обычной тактикой.

## Улучшения

| Найденная проблема | Изменение |
|---|---|
| Далёкий рубеж задачи остаётся за экраном, координаты требуют ручного поиска | «К цели задачи» переносит камеру к Reach либо первой живой цели текущего Destroy |
| В обороне выбрана турель, а первым этапом должен двигаться резерв | «Выбрать исполнителей» выделяет живых actors Reach; на Destroy выбирается профильный класс операции |
| Ручной StartBattle заново выбирал первую машину с двигателем и оружием | Для операции сохраняется действующая группа/управляемый слот; при пустом выборе есть поиск профильного живого союзника, включая стационарную T3 |
| Область карточки задачи должна блокировать ввод карты | Карточка получает общий PanelRoot и RelativeCursorPosition; её область блокирует ввод карты |

Выбор центрирует управляемого исполнителя и открывает его страницу roster.
Кнопки скрыты при результате задачи и ожидании окончательного боя после
всех этапов. Чужая generation не даёт перейти к старой цели. Нажатия не
отдают боевых приказов, не выбирают тактику вместо игрока и не меняют SIM.
Для Destroy переход учитывает текущую позицию живой цели, а не её спавн;
порядок целей берётся из authored actors.

Профильный выбор на Destroy не означает, что остальным запрещено помогать:
весь союзный отряд по-прежнему доступен через roster/рамку/«Все».
Расстановки и боеприпасы в этом проходе не меняются.

## Альтернативные решения

Отдельный проверочный driver использует текущий MissionRun, тот же RON,
физический SIM, physics4/nav8/Rayon4 и обычные публичные Move/Auto/Attack.
Геймплейные значения и здоровье не переопределяются.

| Операция | Другое решение | Результат | State hash |

|8, танки против T2|После прежнего рубежа обход через6040,2050 вместо6040,3320; затем обычная атака оставшейся цели|Victory2446,8 из8 живы; все этапы и ledger пройдены|c45590aa0c9ef41d|

Северный обход T2 медленнее квалифицированного южного2058, но в этом
детерминированном прогоне сохраняет на один танк больше. Это реальная
альтернатива маршрута, а не изменение сложности под тест. Разница хешей
ожидаема из-за других приказов. У T1 Auto выбирает цели сам; расстановка
позволяет выиграть и без единственной предписанной очередности целей.
Это две дополнительные проверенные тактики, не исчерпывающий поиск.

## Оставшиеся границы

Проверка Reach намеренно не объявляет гибель всех двигателей универсальным
провалом: живой корпус может двигаться под действием общей физики и тарана.
Утрата нужного числа живых cores уже даёт явный провал, а живой участник
внутри рубежа засчитывается независимо от вооружения. Отдельная политика
окончания разоружённых elimination-боёв из307 остаётся открытой.

Мировое сохранение по-прежнему не сохраняет интерфейсный маршрут операции.
Короткие native снимки не доказывают FPS позднего боя. Проверка нескольких
тактик не гарантирует прохождение любой комбинацией приказов.

Артефакты этого прохода: out/scenario-navigation-20261016. Source/data
fingerprints — доказательство контента сборки, не clean-build attestation.
