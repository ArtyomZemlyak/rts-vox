# 501 — x86-64-v3 для целевой AVX2-машины

3 ноября 2026. Артефакты: `out/optimization-501/`.

## Причина и ограничение

Следующий build-level кандидат — глобальное улучшение
[instruction selection](https://doc.rust-lang.org/rustc/codegen-options/index.html#target-cpu)
без изменения исходной логики. `target-cpu=native` отвергнут до сборки: машина замеров
поддерживает AVX-512, а ADR-093 задаёт целевую машину с AVX2 без AVX-512.
Поэтому тестируется `RUSTFLAGS=-Ctarget-cpu=x86-64-v3`, который включает AVX2,
BMI/BMI2 и другие разрешённые инструкции, но не AVX-512. Обычный release остаётся
переносимым до отдельного решения.

## Решение

Изменение **принято как ADR-838**. `.cargo/config.toml` задаёт
`-Ctarget-cpu=x86-64-v3` только для `x86_64-pc-windows-msvc`, в соответствии с
AVX2-машиной ADR-093. `target-cpu=native` и AVX-512 не используются. Исходная
логика, gameplay и переносимость в пределах целевой платформы сохранены.
Обычная `cargo build --release` через config прошла; её 200-тиковый контроль дал
нулевые расхождения по всем36 полям.
