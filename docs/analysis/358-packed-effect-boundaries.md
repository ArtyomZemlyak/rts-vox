# Упакованные границы кубических эффектов

21.10.2026. Запрос — оптимизировать эффекты после доработки внешнего вида.
Работа ограничена CPU-построителем общей поверхности ядерного гриба и
пылевого фронта. Детализация и художественные параметры не меняются.

## Причина и изменение

Прежний Volume хранил Vec<bool> и проходил все49×57×49 клетки, включая
пустоты и внутренние клетки; для занятых проверял до шести соседей.
В Rust элементы Vec<bool> занимают по байту. Теперь строкаX хранится
в u64 для каждой пары(y,z). Объединение эллипсоидов перебирает только
свободные биты в прежней коробке; проверка расстояния и граничного шума
прежняя. Пустые коробки возвращаются до сдвигов, ширина1..64 проверяется.

Шесть масок открытых граней вычисляются для строки сдвигами и соседними
строками. Перебираются только биты их объединения. Цвет каждой наружной
клетки вычисляется один раз; прежний порядокz/y/x/ось/знак сохраняется.
Вершины, индексы, нормали, цвета и alpha прежние. GPU-формат, сортировка,
четыре события/26с, SIM и сохранения не меняются.

Занятость основного объёма:136857→22344 байта, пыли22743→3192 байта,
суммарно159600→25536 байт на событие. Это память рабочей занятости;
массивы вершин/индексов и GPU-память не уменьшаются.

Эксперимент с кэшированием маленьких горячих клубов не принят: отдельный
замер не показал устойчивого выигрыша. Оптимизация не снижает качество
эффектов ради числа треугольников.

## Проверка

Артефакты — out/effects-358/. Сохранены прежние production-модули и
бинарник. mesh-probe.rs напрямую подключает старый/новый построители,
сравнивает все четыре массива меша на14 возрастах от0 до26с, для обоих
слоёв, одного и четырёх событий с ненулевыми разными координатами.
Совпадение точное; затем измеряются60 прогонов после двух прогревов с
чередованием порядка. Это стоимость сборки меша CPU, не FPS и не GPU.

Регрессия в production-тестах сравнивает занятость со скалярным эталоном
для ширин1/12/49/57/64, перекрывающихся клубов у границ, полностью внешних
форм, повторного заполнения столбцов и очистки. Сохранена проверка
отсутствия внутренних/дублирующих граней и наружного winding.

## Замер сборки поверхности

Окончательный прогон после headless-тестов и до сборки игры, без фоновой
компиляции. Число треугольников на каждой стадии совпало с исходным.

Горячий слой не изменён. Небольшое расхождение времени одинакового кода
в двух вариантах отражает шум измерения. Задержки авторитетного
разрушения, GPU-отрисовка прозрачности и передача меша не оптимизируются
этим изменением.

36 headless-тестов fire прошли до нативного рендера, один диагностический
пропущен. Сюда входит новая проверка упакованных строк по скалярному
эталону; существующие проверки стадий, лимитов и render workers проходят.

Release-игра пересобрана;12 архитектурных и3 документных теста прошли.
check --workspace --all-targets --release, fmt --check и git diff --check
успешны; последний выдаёт только прежние предупреждения CRLF.
