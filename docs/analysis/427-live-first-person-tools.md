# 427 — Живые инструменты от первого лица

Запрос: сделать полёт с живыми инструментами удобнее, сместить источник
лазера с линии глаз, сохранить обзор и производительность. Работа выполнена
в существующем нативном Rust/Bevy-рендере лаборатории.

## Исследование и выбор

- [Epic — First Person Rendering](https://dev.epicgames.com/documentation/unreal-engine/first-person-rendering?lang=en-US):
  разделение камеры и ближней геометрии, масштабирование инструмента для
  предотвращения пересечения со стенами, общий проход рендера. В этом
  прототипе выбран один кэшированный меш инструмента в обычном проходе;
  отдельной камеры, render texture и дополнительного освещения нет.
- [Steamworks — Accessibility Features / Camera Comfort](https://partner.steamgames.com/doc/accessibility_features?l=english&language=english):
  настраиваемая чувствительность и комфорт камеры. Здесь введены отдельные
  настройки чувствительности, скорости полёта и вертикального FOV; камера
  без покачивания и крена. Это принятые для нашей лаборатории решения,
  а не утверждение о сертификации доступности.

## Управление

F2 запускает живые инструменты в текущем физическом мире. Основные панели
скрываются, появляются центральная точка прицела, короткие подсказки и
кубический универсальный инструмент справа снизу. Материал, вода, копка,
огонь и лазер используют прежние команды и физические системы.

| Действие | Управление |
|---|---|
| Обзор | Мышь, без удержания кнопки и ограничения краями окна |
| Точный обзор | Удерживать ПКМ, чувствительность ×0,35 |
| Горизонтальный полёт | WASD |
| Высота | Space / Ctrl; сохранены X / Z / C |
| Быстрый / точный полёт | Shift ×3 / Alt ×0,2 |
| Базовая скорость | Shift + колесо; также кнопки в панели |
| Воздействие | Удерживать ЛКМ |
| Инструменты | 1 копатель, 2 материал, 3 вода, 4 огонь, 5 лазер |
| Размер кисти | Q / E |
| Дистанция точки | Колесо |
| Поверхность / точка в воздухе | R |
| Пауза в полёте | P |
| Панели и свободный курсор | Tab или первый Esc |
| Вернуть обзор | Tab, кнопка в панели или клик по сцене |
| Завершить живой режим | F2 / «Готово» |

Базовая скорость по умолчанию 6 м/с; диапазон 0,5–60 м/с. FOV вертикальный,
по умолчанию 70°, диапазон 50–100°. Движение нормализовано: диагональ не
ускоряет камеру; наклон взгляда не заставляет WASD погружаться в образец.
Это свободный летающий инструмент, а не наземный персонаж с гравитацией.

Tab и потеря фокуса освобождают мышь и выключают струю. Возврат фокуса
самостоятельно не захватывает мышь. Клик возврата только возвращает обзор:
до отпускания ЛКМ инструмент не срабатывает. Пауза и переход к панелям
сохраняют текущий мир; выпущенные огненные пакеты долетают по общей физике.

## Источник и прицел

Направление воздействия берётся из актуального положения камеры этого
кадра. Ранее использовался GlobalTransform, обновляющийся позднее, что
давало задержку наведения. Команды указателя передаются существующему
обработчику до следующего фиксированного шага. Частота SIM и лимит не более
одного применения на тик сохранены.

Источник лазера/огня смещён на 36 см вправо, 27 см вниз и 74 см вперёд
от камеры. Цель остаётся в центре прицела. Короткий воксельный DDA между
глазами и соплом проверяет грунт и твёрдые воксели юнитов: источник
втягивается перед близкой стеной; в слишком тесном положении отключается.
Сама струя по-прежнему проверяет препятствия через существующий движок.
Эта ближняя проверка не является отдельной системой коллизий камеры
и не проверяет все типы свободно летящих обломков.

Лазер у камеры стал тоньше, ограничено ближнее свечение, убрана старая
вспомогательная линия от камеры. Между фиксированными тиками визуальное
начало луча следует за соплом; точка попадания остаётся авторитетной точкой
SIM. Физическая мощность и область теплового поражения не уменьшаются.

## Стоимость и проверки

Один инструмент — один меш из пяти кубоидов (120 вершин), один общий
неосвещаемый материал, без теней. Меш и материал создаются один раз,
переиспользуются при движении и возврате из меню. Ближняя проверка ограничена
32 посещениями ячеек; кандидаты юнитов отбираются по короткому отрезку.
Дополнительных полноэкранных проходов и физических сущностей нет.

Пройдено 25 проверок: 6 новых проверок управления/источника/команд/кэша,
3 существующие проверки живых инструментов, 4 проверки геометрии эффектов
и 12 архитектурных проверок. Два ручных бенчмарка геометрии штатно ignored.
Движение за секунду сравнено при 30/60/144/200 кадрах: расхождение менее
0,002 вокселя. Проверены освобождение курсора, отсутствие залипания огня,
защита от выстрела кликом возврата, втягивание перед диагональной стеной,
отсутствие изменений SIM от переключения визуала и реальная команда лазера
со смещённым источником.

Для нативной проверки предусмотрены явные скрытые сценарии `fps-laser`,
`fps-water`, `fps-menu` и `fps-profile`. Они включаются только комбинацией
запуска лаборатории, каталога `--shots` и `RTS_LAB_CAPTURE_CASE`; обычный
интерактивный запуск их не использует. `fps-profile` продолжает применять
реальную команду лазера раз в тик, не захватывает системный курсор и
не сохраняет PNG. Это позволяет измерять работу инструмента в фоне.

Первый замер, при котором общий механизм `--shots` сохранял фазовые кадры
во время измерения, отброшен: запись PNG исказила задержки кадров. Его
артефакты сохранены отдельно в `out/live-fps-20261026/fps-profile-with-capture`.
Измерительный сценарий исправлен, окончательные значения приведены ниже.

Нативные скриншоты окончательной release-сборки визуально проверены:

- `out/live-fps-20261026/fps-laser/0000.png` — луч от бокового сопла,
  компактный корпус, центральный прицел, свободная область обзора;
- `out/live-fps-20261026/fps-water/0000.png` — реальная вода на стене;
- `out/live-fps-20261026/fps-menu/0000.png` — панели, выбор инструментов,
  настройки чувствительности, скорости и FOV; модель и FPS-подсказки скрыты.

Короткий замер: RTX 5090, Vulkan, физический рендер 3840×2160, скрытое окно,
лимит 200 FPS, физика/навигация/compute — 1/1/2 потока. Один восьмисекундный
прогон работающего лазера по бункеру в лаборатории, после загрузки сцены.
Это измерение данной сцены, а не большого боя и не длительный стресс-тест.

| Средний FPS | 191,09 |
| Минимум / максимум по полным секундным интервалам | 190 / 192 |
| 1% low (по среднему времени худшего 1% кадров) | 171,75 FPS |
| p99 времени кадра | 5,721 мс |
| Измеренных кадров | 1529 |
| Тиков SIM за 8 секунд / пропущено | 160 / 0 |

Контекст рендера оставался неизменным; окно не захватывало фокус.
В измерительном каталоге нет PNG. CSV, GPU-тайминги и журнал находятся
в `out/live-fps-20261026/fps-profile`, сводка — в
`out/live-fps-20261026/summary.json`. Скрипт воспроизведения:
`out/live-fps-20261026/capture.ps1 -Case fps-profile -Measure` (нужен свежий
каталог результата). Окончательная release-сборка обновлена.

Ручная проверка ощущения от мыши пользователем всё ещё полезна: скрытые
кадры и тесты событий не заменяют субъективную оценку чувствительности.
