# Завершение UI-итерации 596 — повторная квалификация 602

Дата: 2026-11-14. Работа продолжает существующие незакоммиченные изменения.
Активный объём — UI; механическая очередь не заменялась и не исполнялась.

## Исправления

- Единственный окончательный владелец `construction::Root.display` —
  `construction::sync_visibility`, после проекции текущего кадра и перед
  подсказкой каталога. Расчёт содержимого и геометрии отдельно от показа.
  Даже когда не производящий паук запрашивает Sandbox-каталог, видимая
  голограмма исключает нижний каталог. При закрытии проекции каталог
  восстанавливается только при действительном запросе контекста.
- В исходном свежем кадре паука дублирование уже не наблюдалось: позднее
  скрытие из предыдущей работы действовало. Эта приёмка не выдаёт такой
  исходный кадр за воспроизведение дефекта; устранены конкурирующие записи
  видимости и добавлена ECS-проверка переходов.
- Белый текст, голубой фокус, общие стекло/рамка/приглушённый текст используются
  голограммами, HUD, лабораторией, главным и вторичными меню. Янтарный
  рабочий прогресс и ресурсы сохранены. Лабораторные выделения и активные
  команды согласованы с голубым фокусом.
- Старые отдельные зелёные состояния и цвета текста настроек заменены
  общими токенами; нажатие тоже использует общий отклик. Рамка настроек
  следует содержимому, а длинный список ограничен высотой окна и прокручивается.
  Страница настроек сохраняет нативный размер надписей в 960×540 вместо
  уменьшения до половины. При выходе ограничение высоты снимается.
- Новый кадр командира использует отдельную сцену: объект 0 действительно
  Commander; camera exposed, zoom 1.3. Заголовок и видимая модель совпадают.

## Полный набор референсов

Все девять направлений из `docs/ui-optical-work.md` сверены по сохранённым
preview, а не по двум последним картинкам: угловые рамки и очередь; T-уровни
и янтарный прогресс; два чистых бело-голубых HUD; оптические силуэты;
растр миниатюр; композиция PERIMETER и узкая типографика; яркий и спокойный
варианты проекторов. Унаследованные прозрачные миниатюры настоящих моделей,
лучи/источник/глубина, проявление и затухающая подсветка сохранены.
В ячейках только модель и название; реальная стоимость — в отдельной подсказке.

## Проверки

Финальные compile inputs: `a2af2dbbe926a4c5137d8682c2dfce1d23604d8e177356b573c42f5cb73563a2`.
20 UI-проверок прошли на этом входном хеше; см. out/ui602/checks.json.
Узкие проверки используют функции `scripts/test-fast.py`: локальный MSVC,
validation lock, точный inventory, один тестовый поток, проверка входного хеша.
Прямой native bin адаптер нужен потому, что test-fast CLI не имеет target bin.

Предыдущий этап дал 21 успешную UI-проверку, включая настоящий рецепт/очередь
и блокировку карты. После правок только настроек — 20 быстрых UI-проверок.
Дополнительный тест настроек на полном боевом debug-мире не завершён и
не засчитан; его лог сохранён отдельно. Этот дорогой fixture повторно не запускался.

Кадры сняты нативным CLI с паузой для осмотра UI. Это не боевой FPS,
не проверка шагающих и не утверждение о работе мыши через ОС.
Рецепты, кнопки и клавиатурные пути дополнительно покрыты выбранными UI-тестами.

После компиляции обновлён только прежний тест каталога: подключён финальный
проход видимости и требование имени без цены в ячейке. Файл cfg(test) не входит
в release dep-info. Повторная проверка Cargo ничего не компилировала,
exe сохранил хеш; исходная компиляция и cache-validation записаны раздельно.
Старый полный fixture компилируется, но повторно не исполнялся.
