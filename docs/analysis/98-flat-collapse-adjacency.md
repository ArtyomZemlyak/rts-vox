# Плоский кэш контактов графа обрушения

24.09.2026, ADR-405, P-45. База — `1d17e42`.

## Что изменилось

На километровом полигоне к концу длинного проезда граф содержит
189 747 известных чанков, 379 654 компоненты и 1 125 810 контактов.
Кэш соседей хранил по одному динамическому вектору на локальную
компоненту. Поиск опоры многократно проходил короткие списки, разбросанные
по памяти.

Контакты одного чанка теперь хранятся в едином массиве `CachedLink`.
Начальные смещения компонентов задают их срезы. Кэш перестраивается
при прежних событиях изменения разметки и граней. Стабильная сортировка
по локальной метке сохраняет исходный порядок контактов: сначала грань,
потом ребро на грани. Формат сохранения и физические правила не менялись;
после загрузки массив восстанавливается из тех же сохранённых граней.

Упаковка убирает множество мелких выделений памяти. Счётчик
`graph_bytes()` теперь учитывает ёмкость плоского массива и смещений.
Отдельный пик памяти процесса в этом прогоне не измерялся, поэтому
сокращение общего RSS не утверждается.

## Замер

Оба исполняемых файла собраны в release. Исходный сохранён как
`out/backlog/adr-405/bench-range-before.exe`. Каждый вариант запущен
дважды на одной карте и маршруте без выстрелов:

```powershell
.\target\release\bench_range.exe --range data/range-km.ron --move 2200,336 --ticks 6500
```

Фазы обрушения вызываются не в каждом тике; их p99 рассчитан только
среди вызовов соответствующей фазы. В таблице диапазон двух прогонов,
миллисекунды.

| Метрика | До | После |
| --- | ---: | ---: |
| p99 поиска опор | 12,471–12,659 | 7,673–7,771 |
| p99 обновления меток графа | 1,329–1,336 | 0,437–0,462 |
| p99 продвижения фронтира графа | 2,177–2,188 | 1,432–1,548 |
| p99 полного CPU-тика | 16,911–17,015 | 10,820–10,940 |
| Снятые клетки мира | 128 349 | 128 349 |
| Круги четырёх патрулей | `0,5,1,5` | `0,5,1,5` |
| Итоговый хеш | `bb4a604c28e62856` | `bb4a604c28e62856` |

Хвост полного CPU-тика улучшился примерно на 35–36 % на этом маршруте.
Максимумы отдельных тиков после изменения всё ещё достигают 24–25 мс;
стабильные 120 FPS не достигнуты. Стенд не измеряет рендер и GPU.
Сырые журналы — `out/backlog/adr-405`.

## Отвергнутые варианты

- Байтовые метки посещения с эпохами вместо битового массива не дали
  устойчивого выигрыша p99 и добавляли память; правка удалена.
- Байтовая карта достижимости вместо битовой увеличила p99 поиска до
  14,180–19,571 мс; правка удалена.
- Дополнительный проход по одношаговым опорам дал p99 поиска 14,265 мс
  в пробном прогоне; правка удалена.

## Проверки

Тесты `voxel` сравнивают быстрый поиск с полным эталонным обходом
на циклах, устаревших узлах, больших локальных метках и после загрузки.
Отдельный тест требует прежний порядок граней и рёбер при перемежающихся
локальных метках. Прошли 132 релизных теста `voxel`, четыре golden-теста,
19 тестов сохранения и полный `cargo test --workspace`; линтер
`voxel`/`sim-core` не нашёл предупреждений. Форматирование и релизная
сборка нативного `blast` прошли. Контрольный
`sim-cli --seed 42 --ticks 1000 --dump-hash` завершился прежним хешем
`12bd9cb0d53498f2`.
Длинный замер подтверждает прежние разрушения, круги патрулей и хеш.
