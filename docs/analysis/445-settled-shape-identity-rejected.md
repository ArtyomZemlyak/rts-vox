# 445 — Identity fast path `SettledShape`: отклонено

2 ноября 2026. Артефакты: `out/optimization-445/`.

## Гипотеза

`SettledShape::new` для identity basis вычисляет radius общей формулой суммы
абсолютных basis-компонент. Прототип заменил её на `[half;3]`, сохранив общий
расчёт для повернутых форм. Ожидалось меньше fixed-point операций при сборке
irregular shapes.

## Проверки

- Irregular corner, tumbling и порядок cell lists на1/4 workers прошли.
- Release-сборка прошла.
- Все36 нетайминговых полей каждого тика совпали; hash `ef96977a5b55489b` прежний.

## Измерения

Baseline `out/optimization-444/current-825.exe`.
World AI-vs-AI,1600 тиков,physics4/navigation8/Rayon4, порядок «после/до».

| Показатель | Baseline | После | Изменение |
|---|---:|---:|---:|
|Полный mean|30,349 мс|30,649 мс|+0,99%|
|Позднее окно1201–1600|42,847 мс|43,480 мс|+1,48%|
|`debris`|12,769 мс|13,081 мс|+2,44%|
|`settled_cells`, позднее окно|4,442 мс|4,815 мс|+8,40%|

Быстрого пути по времени нет. Ветвление и текущий layout ухудшают результат вместо
ожидаемого сокращения арифметики. Обратная серия не оправдана.

## Решение

Прототип отклонён, исходная формула radius восстановлена. ADR не создаётся.
Небольшая алгебраическая экономия не гарантирует ускорение полного тика.
