# 460 — `unit_boxes` в capture: смешанный эффект, не принято

3 ноября 2026. Артефакты: `out/optimization-460/` и
`out/optimization-443/after-460.*`.

## Гипотеза

Capture-слисы повторно вызывали `bounds_aimed` для тех же frozen тел, хотя
`Explosion::unit_boxes` уже кэширует измерения по body sizes. Прототип заменил свежий
вызов на существующий cache без изменения поз, карт или порядка контактов.

## Проверки и baseline failure

- Все181 nuclear hash совпали, ledger сбалансирован, hash `ae3798a582873796`.
- Все35 полей ordinary1600 совпали.
- `capture_bounds_and_saturation_match_full_walk_with_dented_overlapping_units`
  падает с 239 вместо180 **и на исходном, и на изменённом коде**. Это существующий
  baseline failure, не регрессия кандидата; он не исправлялся в этой работе.

## Производительность

Nuclear, тот же snapshot и181 тик:

| Показатель | ADR-827 | `unit_boxes` в capture | Изменение |
|---|---:|---:|---:|
|Mean tick|17,548 мс|17,551 мс|практически нет|
|Худший тик|38,080 мс|32,738 мс|−14,03%|
|`physics_wave_capture`|22,562 мс|21,633 мс|−4,12%|
|`physics_wave_claims`|559,703 мс|552,473 мс|−1,29%|
|`physics_wave_read_ground`|173,537 мс|175,753 мс|+1,27%|

Уменьшение capture/max не превратилось в устойчивый общий выигрыш. Ordinary серия
также содержала аномальные общесистемные времена и не даёт независимого подтверждения.

## Решение

Изменение отклонено как не дающее доказанного общего ускорения. Прямой `bounds_aimed`
восстановлен. Restored release на200 тиках дал 0 расхождений. Строгий cumulative
остаётся в [454](454-cumulative-827-measurement.md).
