## Общий движок

RangeMound — опциональные min/max в данных, не обработчик сценария.
Нормализованный целочисленный эллипс с квадратичным затуханием создаёт
плавное подножие и округлую вершину. Шесть форм объединяются максимумом:
три основных массива и три смещённых плеча. Предел16 форм, кандидаты
из существующих128×128 bins. Генерация считает формы на уровне колонок,
не повторяет их для каждой высоты. Точечные запросы используют ту же
формулу и локальных кандидатов. Дороги, деревья, material/column и
редакторские ориентиры учитывают авторский рельеф.

Добавление/перенос/удаление формы обновляет старые и новые области с
запасом28 клеток для выступающих крон. Тест сравнивает warm reset со
свежей фабрикой, occupancy, колонки, hash и следующие тики.

Рвы и постройки — обычные RangeBlock. Земля, бетон и сталь повреждаются
общими взрывами, лучами и механизмом обрушения. Новых физических тел
при загрузке гор не создаётся. Движение, баллистика, урон, квоты,
расстановка армий и размер мира ради карты не изменены.

Пустое mounds не сериализуется, старые раскладки читаются с прежним
рельефом. Содержимое нового мира намеренно меняет snapshot/hash.
Старое сохранение хранит свою карту; чтобы увидеть новую, нужен новый
запуск полигона/боя, а не загрузка старого сохранения.

## Пойманные проблемы

1. Прямоугольные RangeRamp давали три огромных пандуса. Native-кадры
   показали неприемлемую форму: эта версия отклонена, добавлен общий
   округлый рельеф. Лимиты мира и геометрии не повышены ради картинки.
2. Дальний маршрут через крытый цех уходил в обход и застревал у угла.
   Центральный проезд открыт сверху между двумя крыльями; фактический
   маршрут танка после изменения проходит.
3. После округления прежняя контрольная цель оказалась над вершиной.
   Цель перенесена в склон; все секторы снова получают реальное попадание.
4. Полный SIM-прогон обнаружил отказ восстановления допустимой большой
   раскладки из-за прежних64 КиБ текста. Предел читателя256 КиБ, прежний
   u32-префикс/UTF-8 RON и версия снимка сохранены. Проверены полная карта
   выше прежнего предела и реальный payload сверх нового потолка.
5. Editor clear/range-guide читали только старую процедурную высоту.
   Они учитывают mounds. Расчистка обрезается потолком мира; при переносе
   вниз ограниченный сверху air-блок сохраняет открытый верх.
6. Launcher позволял выбрать только секторы1–12. Параметр теперь
   принимает1–16, в пределах общего каталога.
