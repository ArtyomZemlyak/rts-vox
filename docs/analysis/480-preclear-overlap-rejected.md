# 480 — Overlap pool snapshot и Settled preclear: отклонено

3 ноября 2026. Артефакты: `out/optimization-480/`, не новый ADR.

## Гипотеза

Pool snapshot и очистка Settled scratch независимы, но выполнялись последовательно.
Прототип вычислял precleared-флаг заранее и вызывал pool/очистку через `rayon::join`,
после чего обычный builder не очищал buffers повторно. Другие вызовы сохраняли
исходную очистку, новых persistent данных не было.

## Проверки

200 тиков и две полные серии по1600 на physics8: все36 нетайминговых полей каждого
тика совпали.

## Решение

Прототип отклонён и полностью откачён. Перенос очистки раньше увеличивает contention
вместо устранения полезного барьера. ADR-830 overlap shapes+cells сохраняется;
replay не запускался при отсутствии улучшения полного тика.
