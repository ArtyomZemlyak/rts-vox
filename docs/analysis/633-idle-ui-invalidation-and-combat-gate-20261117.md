В UI найдены повторные записи, которым не соответствует изменение изображения:

- 192 скрытых штриха motion-пула повторно записывали `Node.display=None`.

  события с нулевым множителем после завершения события.

при появлении материала публикуются текущие uniforms. Геометрия текста,
приказы, тайминги анимаций, интенсивность эффектов, SIM и data не менялись.
