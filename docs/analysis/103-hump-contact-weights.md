# Коэффициенты подъёма гусеницы

25.09.2026, ADR-410, P-45. База — `ba4701d`.

## Причина и изменение

Для каждого положения машины зонд дважды проходит промежуточные точки
между опорами левого и правого борта. Доля расстояния и вес подъёма
зависят только от длины базы и участка плавного входа на выступ, но
раньше в каждой точке снова выполнялись два деления фиксированной точки.
У танка из данных 25 единиц между центром и передней опорой; один полный
запрос высот повторяет этот расчёт почти сто раз.

Зонд теперь вычисляет эти коэффициенты один раз для пары
`(длина опоры, участок входа)` и использует их для последующих поз.
При смене геометрии или длины контакта таблица пересчитывается. Исходные
операции `Fx::div` и порядок применения весов не меняются; таблица
существует только во время запроса и не входит в снимок или хеш.

Также проверено и отклонено повторное использование выделенной памяти
локального окна высот между машинами. Два длинных прогона показали лишь
небольшое снижение медианы движения и почти прежний p99; усложнение
интерфейса полигона не осталось в коде.

## Замер

Два прогона старого и два нового release-бинарника на одной машине:

```powershell
.\target\release\bench_range.exe --range data/range-km.ron --move 2200,336 --ticks 6500
```

| Метрика | До | После |
| --- | ---: | ---: |
| p50 `motion`, мс | 1,669–1,678 | 1,638 |
| p99 `motion`, мс | 5,039–5,056 | 4,805–4,822 |
| p99 полного CPU-тика, мс | 10,378–10,433 | 10,223–10,494 |
| Снятые клетки | 128 349 | 128 349 |
| Круги патрулей | `0,5,1,5` | `0,5,1,5` |
| Итоговый хеш | `bb4a604c28e62856` | `bb4a604c28e62856` |

В двух парах 600-тиковых прогонов с одним энергетическим выстрелом
p99 движения 4,005–4,075 → 3,875–3,886 мс, p99 полного CPU-тика
6,382–6,569 → 6,053–6,265 мс. Каждый прогон снял 46 645 клеток,
хеш `c6373dfde61c255c` и круги патруля прежние.

Изменение устойчиво сократило измеренную стадию движения, но p99
полного тика длинной поездки перекрывается из-за пиков обрушения.
Это CPU-стенд без рендера и GPU; 120 FPS во всех сценариях не достигнуты.
Бинарник базы и сырые журналы — `out/backlog/adr-410`.

## Проверки

Новый тест сверяет каждый вес с прежним точным делением `Fx`, меняет
базу и длину контакта в одном зонде и сравнивает полученные высоты со
свежим зондом. Прошли `cargo test --workspace`,
`cargo clippy --workspace --all-targets -- -D warnings`,
`cargo fmt --all --check` и релизная сборка нативного окна `blast`.
Контрольный `sim-cli --seed 42 --ticks 1000 --dump-hash` сохранил
хеш `12bd9cb0d53498f2`.
