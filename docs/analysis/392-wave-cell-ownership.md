# Точное определение ячейки волны без деления на каждый кубик

24 октября 2026, продолжение391. Артефакты: out/optimization-392.

## Выбранный путь

Профиль391 выделяет body_map около6,2мс в тяжёлом tick911.
В bucket для каждого кубика корпуса вычисляются три координаты владельца
по Q32.32-положению. У не двоичного ребра выполнялись три знаковых
64-битных деления. Двоичные рёбра уже использовали точный сдвиг.

floor(delta / (edge * 2^32)) равен floor((delta >> 32) / edge).
Целая часть delta всегда помещается в i32. Для её беззнакового модуля
заранее считается ceil(2^32 / edge); умножение и сдвиг дают оценку
частного, завышенную максимум на1. Сравнение произведения на edge
исправляет эту единицу. Для отрицательного аргумента возвращается
евклидов частный, включая дробные координаты около границ.

Для соседних вокселей не двоичной сетки сначала проверяется точный
полуоткрытый Q32.32-габарит предыдущей ячейки владельца. Если мировая
координата внутри него, сохраняется прежний владелец и результат
candidate_box, без новых делений. При выходе применяется точный делитель.
Проверка разрешена только при уже найденной ячейке; габарит обновляется
вместе с ней. У двоичных рёбер сохраняется прежний дешёвый путь сдвигов.

CellDivisor существует локально при обходе слоя тела. Расположение,
порядок, состав контактов и их каноническая сортировка прежние.
Двоичные рёбра сохраняют исходный shift. Масштаб вокселя, квоты,
оружие и параметры данных не меняются. Приближение здесь используется
только для вычисления проверяемой оценки целочисленного частного;
окончательный ответ точен, ошибка физики не вводится.
