## Найденный пробел воспроизведения

`profile-range.ps1` безусловно добавлял `--stock-tuning`. Обычный запуск
загружает `out/range-tuning.txt`; локально сохранены 23 значения, включая
`melt.3=60` при штатном360, настройки движения танка, оружия и картинки.
Это не температура в градусах: `melt` задаёт порог накопленного тепла
материала. Значение60 означает более раннее оплавление стали ландшафта;
термальная модель самих тел имеет отдельные параметры.

Профили со stock не воспроизводят пользовательские настройки и не
опровергают его наблюдение. В saved-прогоне уже к тику2130 удалено
2 262 332 клетки — другой исход боя, не идентичная нагрузка. Само по
себе это не доказательство источника паузы на секунды.

Исправлен runner (ADR-720): opt-in `-SavedTuning`, обычный default остаётся
stock. Saved-mode не передаёт `--stock-tuning`, фиксирует наличие/отсутствие
файла, SHA-256 и копию исходных значений. Изменение/создание/удаление файла
во время прогона делает запись невалидной. Файл игрока не редактируется.
Analyzer не разрешает пару stock/saved даже при отсутствии файла;
старые manifests соответствуют stock. Данные для старых обычных benchmark
не подменяются новыми пользовательскими настройками.

## Статус и воспроизведение реального эпизода

Исправлен **пробел воспроизведения настроек**; устранение секундных
фризов не заявляется. SIM/баланс/сохранения и установленный executable
не менялись, пересборка игры не требуется. Совокупно полных захватов18мин:
два stock по4мин и saved10мин. Остановленный stock soak не включён.

Для следующего случая используется общий runner:

```powershell
scripts/profile-range.ps1 -Seconds 600 -Scenarios world-battle -SkipBuild `
  -SavedTuning -Maximized -TargetFps 165 -TriggerMilliseconds 100 `
  -OsPressure -RenderTimeline
```

Важны фактические расстановка/число юнитов, камера и действия перед
задержкой. Стандартный preset60 юнитов не заменяет пользовательскую
расстановку. Вопросы об этом и неподвижной камере заданы пользователю;
ответ к завершению замеров ещё не получен. Для ремонта именно эпизода
1–2с нужен его захват/реальная сцена, а не вывод из средних26мс.


Финальная проверка артефактов: SHA установленного native совпадает с
frozen before; SIM-исходники не изменены. Saved-file SHA до/после совпадает
с raw-копией manifest, в Arguments отсутствует --stock-tuning. Итоговые
132 analyzer tests, PowerShell suite, docs3 и diff check прошли.
