На старте проверки `main` и свежий `origin/main` совпадали на `0c6386c`.
Это отдельное точное улучшение хранения внутри Settled, ADR-709.
Дельта отпечатков из [284](284-rubble-print-delta.md) включена в обеих
ветвях. Полный capture/progress валки остаётся открытым; данный малый

## Изменение и его границы

Маска запросов уже объединяет 64 вертикальные клетки индекса в слово.
Однако ключ `[x, word, z]` повторяет нулевую координату слова почти везде.
В каждой из восьми прежних X-полос теперь две query-only таблицы:

- `word=0`: полный знаковый ключ `(i32, i32)` X/Z и прежний `u64` Y-маски;
- остальные слова: исходный ключ `[i32;3]`, включая отрицательные высоты.

В main-motion маске world7200 **99,10% потиковых записей** имеют word=0;
в окне 6601–7200 — **99,24%**. Это доля записей, не доля CPU/полётов.
Среднее за тик — 44 853 нулевых и 407 остальных записей; поздно —
77 801 и 598. Счётчики наблюдают число живых слов последней motion-фазы,
не число повторных вставок и не все локальные маски rubble.

На Windows x64 payload пары ключ/значение — **16 вместо 24 байт** для
нулевого слова. Это размер типа; суммарный RSS, control bytes, capacity
и дополнительные пустые таблицы не измерены этой величиной.
Tuple хеширует обе координаты отдельно. Конкатенация X/Z в один `u64`
не применяется: в FxHasher 1.1 её младшие hash-биты плохо различают
координату, помещённую в старшие 32 бита. Версия хешера не менялась.

Нулевое слово содержит 64 индексные клетки, то есть 256 мировых единиц
при нынешнем размере клетки 4. Это формат хранения, не ограничение
высоты: другие слова полностью сохраняются. Все диапазоны, биты,
исходные indices и списки кандидатов прежние. Маска перестраивается из
неизменяемого входа; межтикового кэша геометрии или pruning нет.
Высокие карты могут давать другую долю быстрого пути. Изменение общее
для движения обломков и поддержек карты завалов, без условий по сценарию,
юниту или оружию.

## Следующие работы

Полный bounded capture валки при `max_claims`, полезный прогресс и
обслуживание разных источников остаются приоритетом. Данный шаг не
меняет контактные prefix и не исправляет ещё не захваченные растения.
Событийные вклады завалов, полные зависимости опор, EP-03 и GPU-кэши
с динамической инвалидацией остаются открытыми.

Для дальнейшего удешевления Settled стоит отдельно проверить работу
с Y-словом целиком вместо повторных membership-lookup каждой Y-клетки.
Это ещё не реализовано; нужен oracle списков кандидатов/контактов и
полная цена на однослойных и высоких рамках. Сокращать области поиска
из-за заполненного flying-pool по-прежнему нельзя — регрессия 283.
Бюджет каждого тика, group18 ≤100, масштаб 5000 и длительный soak
не закрываются этой сменой ключей.

Финальные `cargo fmt --all -- --check`, `git diff --check`, architecture/docs
прошли. Проверены 332 локальные файловые ссылки шести актуализированных
анализов, отсутствующих файлов нет; anchors отдельно не проверялись.
