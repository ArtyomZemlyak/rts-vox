# 492 — Fat LTO для release

3 ноября 2026, ADR-836. Артефакты: `out/optimization-492/`.

## Причина

Release использовал `lto="thin"` при `codegen-units=1`. Горячие Fx/physics пути
пересекают границы crates, поэтому fat LTO мог улучшить inlining без изменения исходной
логики. Это эксперимент конфигурации сборки, а не алгоритма.

## ADR-836

`[profile.release] lto = "fat"`. Остальные настройки (`opt-level=3`,
`codegen-units=1`, `overflow-checks=true`) и bench profile прежние. Новых зависимостей
и изменений кода нет. Время/объём сборки увеличиваются и не смешиваются с runtime метриками.

## Проверки

- 200 тиков: все36 нетайминговых полей совпали.
- Две ordinary ABBA серии по1600: все36 полей каждого тика совпали.
- Replay snapshot300→600 на physics1/4/8: `695327e0588d053c` во всех режимах.

## Границы

Это не изменение gameplay или retained-history lifecycle. Небольшой общий выигрыш
подтверждён отдельно в headless и native; коэффициенты этих режимов не смешиваются.
Увеличенное время сборки — цена принятого release profile.
