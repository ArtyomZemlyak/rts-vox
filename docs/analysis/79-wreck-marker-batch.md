# Пакетное удаление старых записей обломков

24.09.2026, ADR-386, P-45. При повторном подъёме осевшего фрагмента
симуляция удаляла его запись из `wrecks`, фильтруя весь список. Подъём
нескольких фрагментов в одном тике повторял этот полный проход для
каждого. Теперь ключи поднятых и объединённых фрагментов собираются,
список фильтруется один раз, а новые записи приземлившихся за этот тик
фрагментов добавляются после него. Это сохраняет случай, когда один
фрагмент проснулся и сразу снова приземлился.

23 теста `burst::tests` прошли; проверка толчка фрагмента движущимся
корпусом дополнена сверкой его новой записи. Бой 4×4 на 900 тиках
сохранил хеш `b9c72d156327666e`. После изменения p99 CPU-тика в
одном release-прогоне — 12,645 мс против 12,022 мс в предыдущем;
это разброс отдельных прогонов, измеримого выигрыша обычного боя нет.
Бюджет 8,33 мс для 120 FPS остаётся открытым; основная стоимость
профильного боя всё ещё в захвате сопротивления взрывов и движении
обломков.
