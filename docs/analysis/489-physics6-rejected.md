# 489 — Шесть physics workers: отклонено

3 ноября 2026. Артефакты: `out/optimization-489/`, не новый ADR.

## Гипотеза

После крупного выигрыша physics4→8 нужно было проверить, не даёт ли physics6 лучший
компромисс между восемью независимыми stripes и contention.

Один и тот же ADR-834 binary, World AI-vs-AI, две пары по1600, navigation8/Rayon4.
Все36 нетайминговых полей каждого тика совпали.

## Решение

оптимален, никакой конфигурации не меняется.
