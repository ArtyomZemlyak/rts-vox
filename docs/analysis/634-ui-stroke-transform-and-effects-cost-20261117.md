## Текущая реализация

Изменены только ui_motion.rs, optical_ui.rs и optical_ui.wgsl:

- Декоративный штрих имеет постоянный layout1×1. Translation/scale/rotation
  сохраняют его конечные точки и толщину. Появление/исчезновение меняет Node,
  движение — только UiTransform. Пиксельное округление отключено только у этих
  элементов, чтобы масштаб0,5 не превращал размер в ноль или двойную длину.
- Поиск motion-целей фильтрует только те классы, которые могли получить роль
  и раньше. Выходные фоны обрабатываются только у Tracked. Критерии видимости,
  выбор, задержки управления и тайминги не менялись.
- Шесть vec4 материала объединены штатным AsBindGroup в один96-байтный uniform
  binding. Алгоритм рисунка и значения полей WGSL сохранены.
- Не повторяется та же тень/цвет. Полностью прозрачный спокойный CRT MaterialNode
  снимается до следующего события; native фон и текст остаются.

Новая ECS-проверка подтверждает неизменный change tick Node при движении,
конечные точки affine для масштабов0,5/1/1,75/2 и сохранение реакции hover.
Исходные проверки не удалены. Узкие проверки21/21,0failed/ignored,build47,77с,
tests0,158с. Cached dev build50,018с. Три native-сценария прошли без ошибок
шейдера:540p HUD/лаборатория и4K HUD,38кадров,пять JPEG реально просмотрены;
в обоих motion-сценариях произведены и завершены два изделия.

Старый скрипт требовал двустороннего перекрытия frame-marker bounds и поэтому
отклонял также подтверждённое ускорение1080p. Исходный false-результат не
перезаписан. Исправленная направленная проверка допускает перекрытие или
ускорение: current_upper >= before_lower. Подтверждённое замедление остаётся
отказом; численная терпимость и ширина bounds не расширены. Отдельные assertions
подтвердили сохранение отказаK/L и первого прототипа. Подробности:
out/ui-bindings634/effects-direction-review.json. Это лишь предварительный
допуск к новой интеграции, не итоговый performance pass. Frame bounds описывают
момент commit внутри кадра, а не статистический доверительный интервал.
