# Проверка перед слиянием в main — 2026-09-14

Область: накопленная ветка физики и текущие незакоммиченные изменения,
включая полигон, управление, учёт материи, сохранения и общие модули рендера.
Новые сцены и визуальная проверка в эту работу не входят.

Исправлены следующие ошибки:

- Повторный `Ledger::release` мог зациклить свободный список, а последующая
  выдача — переиспользовать живой контейнер. Членство теперь проверяется
  отдельно; при загрузке проверяются цепочка, живые контейнеры и сумма
  материи в расширенном целочисленном типе. Общий формат Ledger не изменён.
- Резервирование места сразу под целую крупную ячейку останавливало волну
  навсегда, если пул был меньше этой оценки. Сохраняется точный курсор
  ячейки/тела; место запрашивается только для фактического фрагмента.
  Нехватка энергии отличается от временного заполнения пула.
- Загрузка стандартного полигона выводила генератор и состав юнитов
  из текущего оружия. После смены профиля это меняло исходную карту или
  делало снимок нечитаемым. Исходные признаки сцены теперь сохраняются.
- При неудачном поиске пути терялась конечная точка приказа движения.
  Теперь она переживает ожидание и сохранение; остановка и атака отменяют её.
- Масштаб и границы сохранённых поз волны проверяются до их использования.
  Нормализованный базис допускает погрешность целочисленного расчёта.

Расчёт стоимости разрушения вынесен в общий помощник Bursts; им пользуются
полигон и общий мир. Именован тип ключа кеша фрагментов обоих рендеров.
Применён единый rustfmt. Обычные предупреждения Clippy устранены;
локальные исключения для явных параметров ECS и фаз симуляции снабжены
пояснениями. Версия Rust в манифесте согласована с закреплённым Bevy.
Вложения Codex исключены из Git вместе с прочими локальными артефактами.

Снимок полигона: версия 8, без миграции старых локальных снимков.
Раскладки RON совместимы; общий снимок World остаётся версии 10.
Зависимости не обновлялись: изменения Cargo.lock относятся к ранее
подключённым возможностям интерфейса Bevy.

Полный прогон обнаружил устаревшую постановку `small_match`: тест боя с
конечными силами наследовал включённую экономику и выпуск подкреплений
из `Setup::default`. Для этой постановки явно задано `economy: false`.
Требования к смертям, попаданиям и воронкам сохранены. Отдельные тесты
экономики и материальных тел продолжают использовать соответствующие режимы.

Итог: 652 теста прошли, ни один не пропущен. Команды через
`scripts/cargo-local.ps1`:

- `test --release --workspace --exclude render --exclude demo --no-fail-fast` —
  517 тестов, включая GPU, архитектуру, документацию, 175 тестов sim-core,
  19 проверок сохранений и четыре golden-проверки.
- `test --release -p demo --test scenes` — 32 проверки сцен.
- `test --release -p render --lib --bin blast` — 96 тестов библиотеки
  рендера и семь тестов интерфейса полигона.
- `clippy --release --workspace --all-targets -- -D warnings` — без предупреждений.
- `fmt --all -- --check` и `git diff --cached --check` — без замечаний.

Синтаксис всех 14 PowerShell-скриптов проверен без исполнения. Графические
окна и запись не запускались; визуальное качество этим ревью не оценивалось.
Проверялась стандартная конфигурация Cargo; необязательная фича `rt`
в прогон не входила. Эталонные хеши в ходе ревью не менялись.
