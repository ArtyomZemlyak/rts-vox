# 333. Отклонённая группировка одинаковых запросов ячеек опор

Дата:2026-10-19. База:`0387466`. Единственная очередь —
[316](316-optimization-delivery-plan.md). Статус: **не принят**, runtime
полностью удалён перед следующим экспериментом.

## Гипотеза и точность

В каждой X-stripe соседние provider requests с одинаковыми lo/hi получали
общий обход want.column и один lookup ячейки. В список этой ячейки источники
добавлялись в прежнем порядке. Менялся только внутренний порядок arena nodes;
число узлов, состав и порядок контактных списков сохранялись.

Адресные debug проверки:35 passed,2 ignored. Дополнительный независимый
cell-by-cell oracle проверил перекрывающиеся серии A/A/None/A/B/B/A,
отрицательные координаты и границы вертикальных слов, serial/parallel,
1/4/8 workers, очистку и принудительные wide successors.
Это не полный release/native qualification.

отдельно не снималась. Нельзя утверждать, что одинаковых запросов нет.
