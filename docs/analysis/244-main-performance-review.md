## Уже установленные факты

- Компонентные ground claims ADR-659 и региональное удержание обвала
  ADR-645 действительно увеличили полезное разрушение. Большая нагрузка
  после них сама по себе не доказывает регрессию реализации. Возвращение
  блокировки обвала всей карты или прекращение разрушения неприемлемы.
- Весь tick по-прежнему синхронно вызывается из кадра `blast`. Потолок
  долга ограничивает накопление, но не убирает дорогой tick из кадра.
  Даже быстрые промежуточные кадры не доказывают отсутствие длинных кадров.
- `BlastRange` имеет собственные фиксированные пулы: физика по умолчанию
  4, навигация большого боя 8. `profile-range.ps1 -PhysicsWorkers` пока
  задаёт только `RAYON_NUM_THREADS`; это больше не управляет физикой боя.
  `bench_battle` также печатает глобальный размер под именем физики.
  Это ошибка управления/наблюдаемости после введения отдельного пула;
  actual `worker_counts()` в native-логе показывает правильные числа.
- `detach_unanchored` сначала повторно размечает unsupported chunks и
  разворачивает их пробеги в списки вокселей, затем проверяет удержание
  группы. Пока волна держит регион, этот расход повторяется каждый тик.
  Проверяется оптимизация, которая сохраняет порядок готовых групп,
  ограничение размера тела и повторную проверку после освобождения.
- Кеш коробок волны ADR-661 сокращает измерение геометрии, но на каждом
  шаге строит временный вектор размеров каждого юнита. Проверяется цена
  и возможность сравнивать размеры без этих выделений.

Неподтверждённые предположения не считаются исправлениями. Итоговые
находки, тесты, замеры, принятые и отвергнутые изменения будут добавлены
сюда по мере завершения проверяемых срезов.
