# Продолжение пулемётного попадания, 05.10.2026

## Подтверждённая потеря

В P-76 были поздние окна без новых revisions при продолжающихся MG impacts.
Код stream_contact_owned снимал пулю после контакта, но при Deferred body
возвращался без receive_cell и без сохранённого продолжения. Ground также
не сохранял последнюю прибавку работы после Deferred. Лимиты обломков и
число уже принятых попаданий — разные ограничения; нехватка места не должна
аннулировать принятый контакт.

ADR-581 расширяет конечную очередь ADR-580. Обычный доступный контакт
по-прежнему применяется сразу. Только Deferred создаёт direct job: конкретный
ID/part/local cell либо world cell/material, исходная работа и остаток
однократно выделенной material энергии. Уже снятый/переданный источник
завершает контакт без повторного выброса и без урона соседнему источнику.
Физический выброс следует текущей позе; адрес урона остаётся локальным.
Старые dents учитываются один раз; попытка повтора не вызывает Matter.begin.
Unaffordable и Indestructible завершают контакт без дополнительной энергии.
Тепловые paths огнемёта/лазера не изменены этой итерацией.

## Хранение и планирование

Новые producers используют общий max_jobs=128 для pending+solid flight,
включая MG, бронебойный и картечь. Весь парный залп резервируется заранее.
При заполнении новые выстрелы ждут; принятые контакты не исчезают.
Повтор одной прямой клетки расходует один контакт из cells_per_tick=512.
Обработка остаётся циклической, с одним admission scan на фазу; между
atomic batch передаётся остаток свободной вместимости.

Пустая очередь сохраняет канонический snapshot48, только канал/спалл —49;
при наличии direct job появляется50 с тегами источника. Decoder проверяет
пределы длины, локальные ID/части/клетки, материал, форму single-cell job,
остаток энергии и общий outstanding budget. Old49 принимал flying MG
независимо от очереди penetrators: это конечное старое перекрытие допускается
при загрузке до max_jobs каждого класса вместе с его flight (всего до256).
Новые producers не добавляют выстрелов сверх общего128; старое перекрытие
дренируется. Golden-формат основной симуляции не менялся.

bench_battle --damage-trace добавляет damage_machine_gun с pending и
разностями completed/retries/blocked. Blocked включает initial Deferred
как body, так и ground; completed может означать пропуск уже снятого
другим событием источника. Это не равнозначно числу разрушенных кубиков.
Общие kinetic counters/CSV теперь также включают прямые continuations;
фаза kinetic_resume остаётся общей. Все counters отсутствуют в save/hash.
