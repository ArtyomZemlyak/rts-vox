# 328. Компактные результаты посадки обломков

Дата: 2026-10-19. База: `main 12300a8`; очередь —
[316](316-optimization-delivery-plan.md), узкий срез обслуживания debris.
Статус: не принят, runtime прототип удалён; замеры сохранены.

## Причина выбора

После327 late debris и rubble сопоставимы. В обычном логе327 позднее
settled занимает3,2–3,4 мс, translation1,2–1,5 мс, ключи/группы слияния
примерно по0,3 мс. В диагностическом snapshot6000→6128 parent debris
около6,67 мс, но детальные mutex observers и горячий интервал отличаются
от ordinary6000: их absolute timings нельзя смешивать. Inclusive worker
spans не суммируются с parent как независимое время.

В translate каждый вызов `advance_fragment` прежний; для resting он
возвращает false. Старый сборщик всё равно пишет один Option<Wreck> на
каждый фрагмент, после чего проходит этот массив, оставляя только посадки.
Так полная холодная история создаёт промежуточные результаты каждый тик.

## Проверяемое изменение

Пачка256 исходных slots сохраняет физическое обновление каждого куска,
но выдаёт только Some(Wreck). Indexed collection пачек и объединение
в порядке пачек сохраняют прежний source order посадок. Малые списки
используют последовательный filter_map. Wake commit, выделение вместимости,
advance/contact/evict/substeps/tumble/landing, порядок слияний и ledger
не меняются. Нет сохранённых ответов, новых ревизий или межтикового кэша.

Это сокращение промежуточного результата, **не active-ID индекс05a**:
все прежние куски всё ещё посещаются и обновляются. Размер intermediates
зависит от фактических посадок и числа пачек вместо одного Option на всю
историю. Capacity, плотный случай и цена dispatch входят в полный замер;
снижение общего RSS/VRAM и нулевая цена холодной истории не заявляются.

Гранулярность сама по себе уже проигрывала в126. Эта проба устраняет
плотный массив, а не только меняет размер jobs; без full-tick gain
новый путь не принимается. Полный старый dense collector сохранён
как независимый test oracle (`COMPACT_RESULTS=false`).

## Проверки перед performance gate

Новый differential test:0/1/255/256/257/1023/1024/1025/39495 slots,
workers1/2/4/8, ноль/редкие/все посадки. Проверяются все физические вызовы
ровно один раз, мутации даже без посадки, итоговый список и source order.

Полный kernel oracle сравнил снимки мира/debris/ledger/wrecks с прежним
scalar+dense путём на1100 фрагментах,80 корпусах,20 шагах, с резервами,
движением, настоящим claim и restore. Регрессия zero-room eviction за
исходный sweep тоже прошла. Эти адресные debug проверки не заменяют
полный release-набор или native квалификацию.

Release probe собран locked/offline за1м33с. Источники фиксируются в
`out/optimization-328/source-inputs.json`, baseline — frozen327.
World AIvsAI6000,physics4/nav8/Rayon4, ordinary с tick CSV; подробные
rubble leaf timers выключены. Raw и анализаторы — в том же каталоге.
