ADR-827. Взрывные пики остаются, но не являются причиной позднего среднего времени.

## Что не делать по этому профилю

- Не повторять fused selected/cell partition из отклонённого 441.
- Не принимать persistent/proof/spatial indexes по одному уменьшению counters:
  449–452 уже показали цену инвалидации.
- Не оптимизировать `HashMap::clear` как освобождение capacity: стандартный clear
  сохраняет allocation.
- Не выбирать следующий эксперимент только по короткому раннему бою.

Следующий независимый срез — exact paid claims/capture, пока главная retained-фаза
остаётся предметом отдельного исследования lifecycle, а не ещё одного кэша.
