# 407 — Проверка и доработка интерфейса лаборатории

Дата: 2026-10-25. Задача: проверить и улучшить текущий нативный редактор.

## Свежая проверка

Исходные снимки текущего запуска: `out/laboratory-ui-polish-20261025/before-overview/0000.png`,
`before-weapon/0000.png`, `before-results/0000.png`, 1600×900, Vulkan.
Проверена последовательность: выбор объекта → инспектор → выбор воздействия → результат.
Сохраняются сильные стороны предыдущей версии: миниатюры реальных моделей,
категории внизу, список сцены слева, подписанные иконки, выделение в сцене.

Обнаружено:

- Во вкладке оружия видно только пять из десяти воздействий; явного положения
  прокрутки нет. Для достижения нижних команд нужно догадаться крутить колесо.
- Инспектор танка содержит настройки размера блока и разбор, которые к нему
  неприменимы. Наличие старого выделения во время размещения разрешало
  команды применения размера/материала к прежнему объекту.
- Выбор цели не даёт отдельной инструкции о следующем действии.
- Прежний scroll handler записывал позицию даже при отсутствии её изменения,
  отмечая компонент изменённым на каждом кадре наведения.

## Изменения

Добавлены полосы прокрутки списка сцены и инспектора: размер ползунка отражает
видимую долю, доступны нажатие на дорожку и перетаскивание с сохранением точки
захвата. Выход курсора за дорожку ограничивает прокрутку её краями. Полоса
скрывается, если содержимое помещается. При смене вкладки позиция сбрасывается,
при уменьшении содержимого ограничивается. Модальные окна и потеря фокуса
отменяют drag. Положение и цвета записываются только при изменении.

Инспектор показывает перемещение существующего объекта отдельно от высоты
размещения. Размер доступен для одного блока или новой детали, разбор — только
для составной сборки. Неприменимые команды отключены и в обработчике действий,
включая клавиатурный путь. Пустую новую сборку нельзя сохранить.
Выбор воздействий размещён в две колонки; режим цели содержит инструкцию.

Это работа только в render/UI. Дополнительных тиков физики, проходов по вокселям,
рендер-камер и зависимостей нет. Ограничение обычной игры остаётся 200 FPS.

## Проверки и границы

`cargo check -p render --bin blast -j4` прошёл.
`cargo test --release -p render --bin blast -j4 laboratory`: 18/18,
71.78 с исполнения; компиляция 3 мин 21 с. Новые проверки покрывают нажатие
на дорожку, drag за границы, смену вкладки, уменьшение содержимого,
доступность команд по типу элемента и блокирование прежнего выделения
при размещении. Прежние проверки физики, атомарности размещения,
поворота, переноса/копии и восстановления исходной сессии также прошли.
Сборка и тесты выполнялись последовательно, BelowNormal, affinity 15,
`RUST_TEST_THREADS=1`, `RAYON_NUM_THREADS=4`.

После release-сборки (3 мин 14 с) выполнены девять последовательных скрытых
запусков: общий вид, оружие, результат, пустая новая сборка, отдельный блок,
сценарий выбора цели, оружие/общий вид в 4К и обычный вход без лаборатории.
Все завершились кодом 0 с пустым stderr. Артефакты:
`out/laboratory-ui-polish-20261025/after-*/0000.png`, `plain-smoke/`.
В 1600×900 видны все десять воздействий; в 3840×2160 целиком помещаются
также мощность, цель и сохранение оружия. Для танка скрыта секция размера,
для новой детали она присутствует. Пустая сборка показывает неактивное «Готово».

Снимок `after-aim` выявил ошибку самого capture fixture: режим цели сбрасывался
при входе, потому что у него нет ghost-позиции. Вход теперь различает
явно выбранный проверочный сценарий и обычный вход, вместо проверки наличия
ghost-позиции. Интерактивный вход сохраняет прежнее поведение.
Эта последняя правка касается только установки проверочного состояния.
После неё `cargo check` прошёл; окончательная release-сборка завершилась
за 3 мин 37 с. Четыре целевых запуска `final-aim`, `final-draft`,
`final-weapon-4k`, `final-plain` завершились кодом 0 с пустым stderr.
В `final-aim` видны активный инструмент «Цель» и новая инструкция;
`final-draft` и `final-weapon-4k` открыты и проверены после этой сборки.
Сопоставление `before-weapon` и `after-weapon` выполнено в одном размере
1600×900. Последующие снимки подтверждают сохранение этой раскладки.
После исправления fixture полный набор 18 тестов повторно не компилировался:
пользовательские UI-команды и scroll-система с момента его прохождения не менялись.

Все нативные запуски — Hidden, `--profile-background`, лимит 30 FPS,
physics/nav по одному worker, compute два, BelowNormal, affinity 15.
Работающих проверочных экземпляров игры после проверки не осталось.

Проверки интерфейса не являются замером максимального FPS боя или полной
проверкой доступности через экранный диктор.
