# 426 — Точная ёмкость списков соседей движения

1 ноября 2026, ADR-822. Артефакты: `out/optimization-426/`.

## Изменение

Три пути движения собирали `others` через `filter` и `chain`, поэтому итоговый
`size_hint` не позволял `Vec` выделить точную ёмкость. Теперь каждый путь один раз
вызывает `Vec::with_capacity(positions.len() + 1)` и наполняет буфер через `extend`.
Порядок исходных позиций, gun obstacle, contact IDs и принятие движения прежние.
Это P2-оптимизация представления, а не решение retained history.
