# 478 — Overlap Settled shapes и cell construction

3 ноября 2026, ADR-830. Артефакты: `out/optimization-478/`.

## Причина

После ADR-829 профиль на 3000 тиков показал `Settled` 14,549 мс в позднем окне,
включая 7,884 мс cells. Shape assignment и cell partition/fill были независимыми
последовательными стадиями: первая писала только `shape_index/shapes`, вторая —
`SettledCells`, а обе лишь читали `selected`, `want` и исходные фрагменты.

## ADR-830

Для `fragments.len() >= 1024` shape assignment и `SettledCells::build` выполняются
через `rayon::join` с раздельными mutable fields. Малые входы сохраняют прежний
последовательный путь. Никаких новых buffers, collect, persistent state или изменений
contact order нет. Shape indices и cell lists строятся в прежнем порядке.

## Проверки

- 200 тиков: все36 нетайминговых полей совпали.
- Две ordinary ABBA серии по1600: все36 полей каждого тика совпали.
- Replay snapshot300→600 на physics1/4/8: `695327e0588d053c` во всех режимах.

## Границы

Retained-history объём и полные проходы сохраняются. Это ускорение текущего builder,
а не решение lifecycle всей истории. Новый cumulative baseline оформляется отдельно
и не выводится из headless коэффициентов.
