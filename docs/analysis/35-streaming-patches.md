# Передача изменившихся полос карты

21 сентября 2026. Продолжение P-45 и `34-smoke-and-rays.md`, ADR-335.
Слишком мелкий дым и пропадающий поверхностный выброс закрыты в предыдущем
изменении; здесь устранена отдельная причина длинных кадров при проезде.

## Причина и проверка

Полоса X шириной восемь вокселей давала 245760 отдельных маленьких
выделений памяти при извлечении ресурса в Bevy render world и столько
же освобождений. Полезных данных — меньше мегабайта. Один плотный массив
с адресными диапазонами сохраняет тот же пакет без этой цены.

Ручной CPU-тест `bench_sparse_slab_extraction`, release, пять повторов,
включает извлечение и освобождение. Мир заранее заполнен; чтение файлов
и GPU в измерение не входят:

| вариант | пять повторов, мс |
|---|---|
| отдельные массивы по строке | 17,338 / 15,415 / 13,062 / 12,009 / 12,122 |
| единый массив, слияние диапазонов на месте | 2,713 / 1,681 / 1,412 / 1,189 / 1,031 |

Дополнительно сами полосы публикуют только отличающиеся слова. Пустое
небо не переписывается, одинаковые старые/новые материалы не отправляются.
Уменьшение количества изменений зависит от рельефа: плоская земля
переиспользуется почти целиком, сплошь отличающийся рельеф всё ещё
потребует полного пакета полосы. Такой пакет проверен ручным тестом выше.

## Оконные прогоны

Ryzen 9 9950X3D, доступно восемь логических CPU, RTX 5090, Vulkan,
1600×900, release, все FX, 1×, симуляция 30 Гц. Без VSync, захвата
кадров, GPU-таймеров и одновременно работающего Cargo. После готовности
шейдеров две секунды прогрева. Во всех трёх случаях — одна плоская копия
километровой карты `out/performance-20260920/streaming-x-fixture.ron`,
камера `gun`, приказ (1200,336), 35 секунд / 1050 тиков.

| вариант | среднее FPS | p50, мс | p95, мс | p99, мс | максимум, мс |
|---|---:|---:|---:|---:|---:|
| до ADR-335 (`final-stream`) | 386,4 | 2,319 | 3,597 | 4,386 | 40,580 |
| единый массив (`packed-stream`) | 406,1 | 2,314 | 3,446 | 4,170 | 21,282 |
| плюс только реальные изменения (`diff-stream`) | 413,6 | 2,312 | 3,405 | 4,167 | 20,514 |

Пик извлечения во втором/третьем прогонах — 5,667 / 0,097 мс;
пик CPU-подготовки рендера — 2,265 / 0,955 мс. Таймер извлечения
не включает освобождение старого ресурса; полный кадр включает.
Симуляция во всех случаях заканчивает в (1190,15,345), угол окна
(544,0,0). Это не изменение маршрута ради более лёгкого теста.

Оставшийся максимум 20,514 мс приходится на начало движения: второй
тик физики занимает 17,498 мс. Если отдельно рассмотреть интервал
1…35 секунд, максимумы трёх прогонов — 40,580 / 17,512 / 8,728 мс.
Эта дополнительная разбивка объясняет источник; основной максимум
публикуется целиком, стартовые кадры не исключаются из результата.
Следующий узкий участок — начальные поиски/движение машин, не
передача этой полосы карты. Даже 8,728 мс чуть выше бюджета 120 FPS.

Повтор восьми облаков (`diff-clouds`, 15 секунд) сохранил результат:
213,1 FPS, p50 3,787 / p95 9,678 / p99 10,202 / max 11,559 мс.
Симуляция 450 тиков, восемь полей; ни физика, ни качество FX не урезаны.
Это всё ещё не 120 FPS на каждом кадре свежих вспышек.

## Проверки и воспроизведение

- 111 тестов библиотеки рендера, один ручной бенчмарк игнорируется
  обычным запуском. Несмежные и перекрывающиеся адреса проверены отдельно.
- 10 тестов окна; применение объявленных изменений к старому буферу
  равно полной новой сборке при диагональном сдвиге, скачке, возврате
  и повторе окна, включая повреждённый корпус.
- GPU-тест scatter сравнивает результат с CPU.
- Физика и формат сохранений не изменены. Проверки ядра, golden и
  GPU-поля описаны в `34-smoke-and-rays.md`.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/cargo-local.ps1 test -p render --lib --release bench_sparse_slab_extraction -- --ignored --nocapture
.\target\release\blast.exe --range out/performance-20260920/streaming-x-fixture.ron --view gun --move 1200,336 --profile out/stream.csv --profile-seconds 35
```

Сырые данные и журналы: `out/backlog-20260921/`. Остаток P-45:
первые поиски пути, длинный отказ в лесу, тяжёлый удар/отделение,
несколько свежих вспышек и разреженное хранение для 10 км. Этот
ограниченный набор проездов не доказывает отсутствие всех рывков.
