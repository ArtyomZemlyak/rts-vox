# 443 — Run-length summaries материалов: отклонено

2 ноября 2026. Артефакты: `out/optimization-443/`.

## Гипотеза

`read_ground` повторно сканирует материалы для kind set, отказа клетки и оценки
энергии. Прототип заменил это на `(material, multiplicity)`: один run pass для
смешанных ячеек и мгновенный summary для доказанного `uniform_box`. Остаток энергии
считался как `min(multiplicity, left / price)`, что эквивалентно прежнему
поэлементному вычитанию.

## Проверки

- Все19 contact-read тестов прошли, включая scalar-эквивалент `spent_cell_runs`.
- Во всех трёх nuclear-окнах по181 тик совпали все543 хеша и hash
  `ae3798a582873796`; ledger сбалансирован.
- В обеих ordinary1600-сериях совпали все36 нетайминговых полей каждого тика.

достаточен для принятия.

## Решение

Прототип отклонён, `blast.rs` и `range_contact_read_tests.rs` полностью возвращены
к baseline без diff. ADR не создаётся. Run summary сам по себе не является глобальным
ускорением: дополнительная подготовка и изменение layout/cost остальных фаз важнее
локального процента pack.
