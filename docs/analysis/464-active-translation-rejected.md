# 464 — Ordered active-list translation: отклонён по полному тику

3 ноября 2026. Артефакты: `out/optimization-464/`, не новый ADR.

## Гипотеза

В профиле 459 на тиках 2701–3000 `debris_translate` стоил 4,162 мс при 481 632
фрагментах и примерно 3 900 flying. `advance_fragment` для resting сразу возвращается,
поэтому полный mutable parallel traversal выглядел как глобальная холодная работа,
которую можно удалить без нового кэша.

Прототип формировал ordered active indices в уже существующем pool snapshot, добавлял
фактические wake transitions и обрабатывал только эти индексы. Parallel 256-fragment
chunks адресовали canonical Vec, indexed collection сохранял исходный порядок landed.
Сам `advance_fragment`, Fx, контакты и порядок физики не менялись.

## Корректность

Release World AI-vs-AI, physics4/navigation8/Rayon4:

- 200-тиковая проверка: все 36 нетайминговых полей совпали;
- две полные ABBA-серии по 1600: все 36 полей каждого тика совпали, mismatches=0.

## Производительность

| Пара | Mean tick | Позднее окно 1201–1600 | `debris`, mean |
|---|---:|---:|---:|
| 1, после→до | 32,714→32,691 мс (−0,07%) | 46,542→46,324 мс (−0,47%) | 13,763→13,787 мс (+0,18%) |
| 2, до→после | 32,724→32,855 мс (+0,40%) | 46,461→46,906 мс (+0,96%) | 13,774→13,799 мс (+0,18%) |

Сводно mean 32,719→32,773 мс (**+0,16%**), позднее окно 46,502→46,615 мс
(**+0,24%**), `debris` 13,769→13,793 мс (**+0,18%**). В последнем окне translation
всё же уменьшился примерно с 1,7 до 1,6 мс, но адресация/chunk join и остальные фазы
поглотили локальную экономию. Реальная физика flying, а не ранний return resting,
занимает большую часть этой фазы на стандартном бою.

## Решение

Изменение отклонено и полностью откачено. ADR-827 сохранён, replay1/4/8 не запускался
при отрицательном суммарном результате. Суммарные принятые −10,82% mean tick и −14,17%
позднего окна не изменились.

Полезный вывод для следующего глобального среза: простое исключение ранних return из
одного full traversal недостаточно. Нужно устранять дорогую работу целой фазы над cold
history (прежде всего `Settled`, wake и rubble), а не только её dispatch.
