# P-56: дальность в одиночном полигоне

23.09.2026. Контур дальности, ранее показанный только для выбранного
боевого юнита, теперь появляется у стрелка одиночного полигона с
огнемётом или пулемётом. Радиус берётся из активного `Stream` в
`range-weapons.ron`, то есть из того же ограничения, которое применяет
симуляция полёта и проверка атаки. Контур повторяет поверхность земли,
передвигается вместе со стрелком и использует общий рендер с боевым
режимом.

Для фугаса и энергопушки единый круг не показывается: их баллистика
и препятствия не задают одного честного радиуса. В панели остаётся
название выбранного режима. Проверка компиляцией и существующими
рендер-тестами; оценка читаемости на дальней камере остаётся P-57.
