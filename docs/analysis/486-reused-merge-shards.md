# 486 — Переиспользование merge shard buffers

3 ноября 2026, ADR-834. Артефакты: `out/optimization-486/`.

## Причина

Восемь merge shard vectors создавались и удалялись на каждом тике. Их содержимое уже
построено упорядоченно и не требуется после merge groups, поэтому allocations можно
удалить без изменения join lifecycle.

## ADR-834

`Bursts` владеет `join_shards` как scratch. Builder берёт vectors через `take`, очищает
только логические записи и возвращает после merge groups. `RestingPile` вынесен на уровень
модуля без изменения layout. Scratch не входит в snapshot/hash; source indices, groups,
transfers и ledger прежние.

## Проверки

- 200 тиков: все36 нетайминговых полей совпали.
- Две ordinary ABBA серии по1600: все36 полей каждого тика совпали.
- Replay snapshot300→600 на physics1/4/8: `695327e0588d053c` во всех режимах.

## Границы

Это не persistent membership и не устранение O(retained). Изменено только время жизни
существующих buffers. Native FPS и новый cumulative baseline в этом срезе не измерялись.
