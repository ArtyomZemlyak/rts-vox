# Стартовое меню — 4 ноября 2026

Обычный запуск `blast.exe` и лаунчер `scripts/play-range.ps1` открывают
главное меню. Прямые CLI-запуски лаборатории, редактора, сохранения,
боевых сценариев, съёмки и профилирования сохраняют свой прежний маршрут.
`--main-menu` принудительно открывает меню; `--skip-menu` пропускает его.

## Режимы

- Полигон использует существующий маршрут `RangeMode`.
- Бой против ИИ использует `BattleWorld` на текущей карте полигона.
- Лаборатория использует прежнее сохранение и восстановление сессии.
- Наблюдение ИИ против ИИ использует `BattleWorldAuto`.
- Настройки открывают существующие параметры, сначала вкладку изображения.
- Справка, продолжение сессии и выход доступны в том же меню.

Кнопка «Меню» добавлена в заголовки полигона и лаборатории. F10 открывает
меню; Esc сохраняет приоритет отмены активного инструмента, редактирования
числа, выхода из первого лица и закрытия настроек.

## Приостановка

Меню сохраняет прежнюю паузу сессии и сбрасывает накопленное время кадра
при возврате. Системы ввода карты, живых инструментов, пилота, симуляции,
сценариев и перемотки отключаются условием расписания. Открытие меню
сбрасывает удерживаемые кнопки. Курсор освобождается, камеры мира
отключаются. Исключение — явно запрошенная автоматическая съёмка, которой
нужен прогрев GPU перед сохранением кадра.

Переход из лаборатории в другой режим сначала восстанавливает сохранённую
сессию, затем вызывает обычный обработчик выбора режима. Ошибка подготовки
или восстановления карты возвращает меню с сообщением. Геометрия мира,
правила урона, навигации и физики этим изменением не затрагиваются.
