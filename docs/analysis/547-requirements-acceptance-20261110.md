## Обнаруженный и исправленный дефект

Требование пользователя: механическая рука имеет ограниченный сектор,
корпус доворачивается, инструмент работает из настоящего положения.
В `range_construction.rs` печать/ремонт начинались по готовности корпуса,
пока настоящий инструмент ещё поднимался. Это создавало луч из ненаведённой
руки. Факт наличия плавного решателя в 545 сам по себе не исправлял этот путь.

Добавлено условие `commander_arm_ready`: направление физического излучателя
должно смотреть на объект с допуском 6°, цепь звеньев должна быть цела.
Параметр вынесен в RON, старый RON без поля читается. Проверка используется
и для работы, и для запроса мощности. Передача мощности остаётся общей
со строительством дронами и заводами; нет бесплатного первого рабочего тика.
Формат сохранений и баланс скорости движения не менялись.

Новая проверка полного тика действительно поднимает руку, ждёт первого
оплаченного вокселя, проверяет луч, бухгалтерию и точное продолжение
snapshot/restore. Отдельная проверка восстанавливает ремонт во время
наведения. Проверки чистой скорости/учёта ресурсов стартуют с наведённой
рукой; задержку наведения проверяют отдельные приёмочные случаи.

Дополнительный случай пересекает границу рабочего сектора уже после
распределения мощности: второй командир в той же сети продолжает строить,
а первый не печатает за счёт чужого запроса. Строительная фаза использует
точно тот же снимок индивидуальных запросов, по которому рассчитана сеть.

## Приоритет незавершённого

1. Полноценная комната требует представления нескольких независимых сторон
   в симуляции и сохранениях; одних дополнительных кнопок недостаточно.
2. Кабели/аккумуляторы требуют явных узлов, локального учёта и разрушения
   соединений; нынешний радиус мощности — приближение, а не исполнение запроса.
3. Формация с местами, время полного цикла краулера и художественная приёмка
   тяжёлой походки/моделей остаются отдельными проверяемыми работами.
4. Реальные FPS нужно измерять в выбранном пользователем 4К-бою с указанным
   временем матча. Нагрузка тестов ограничена; тяжёлый прогон здесь не запущен.
