# Фугас, сталь и читаемость струй

23.09.2026, ADR-352. Этот проход по P-50/51/52/53/58/59 отделяет
боевые повреждения от картинки. Все значения ниже получены в release на
одной раскладке `range-cover.ron`, фиксированных 240 тиках и четырёх
мощностях. Воспроизведение: `cargo run --release -p sim-core --bin
bench_shell_balance` через `scripts/cargo-local.ps1`. Исходный и итоговый
журналы: `out/shell-balance-before.log` и `out/shell-balance-after.log`.

| Сценарий | Мощность | Снятые ячейки до → после | Снятые ячейки танка | Итог |
|---|---:|---:|---:|---|
| Открытый танк | 0,5× / 1× / 2× / 4× | 0/0/128/560 → без изменения | 153/306/603/1185 | танк получает реальный локальный урон, во всех четырёх случаях остаётся жив |
| Грунт | 0,5× / 1× / 2× / 4× | 1212/4717/9688/19730 → без изменения | — | масштаб воронки растёт с зарядом |
| Стена, танк за ней | 0,5× / 1× / 2× | 0 → 0 | 0 | лицевая сталь накапливает 1150/2300/4600 работы при новом пороге 6000 |
| Та же стена | 4× | 0 → 19856 | 0 | передняя сторона отколота, сохранившийся массив защищает танк |

Прежний порог стали 10000 превышал даже максимум 9200 работы на
открытой ячейке при заряде 4×: разрушение стены было невозможно в этом
сценарии. Новый порог 6000 сохраняет смысл прочного укрытия на 1× и 2×.
Боевая конфигурация танка переведена с 0,5× на 1×. Сталь корпуса машины
использует отдельное сопротивление ролей и требует самостоятельной
калибровки: этим проходом P-58 целиком не закрыт.

Пулемёт за 30 тиков выпускает шесть парных залпов вместо десяти.
Работа одного попадания 310 → 500, энергия разрушения 60000 → 100000:
сумма по очереди меняется с 3100/600000 до 3000/600000 на ствол.
Тест сверяет оба ствола, повреждение мишени и материальный баланс.
Трассер, искры и вспышка увеличены для камеры полигона. Это не меняет
скорость полёта и дальность попаданий.

Фугас получил краткую центральную вспышку, 24 разлетающихся горячих
кубических языка и 10 ранних клубов. Эффект создаётся в тик физического
попадания; основное облако по-прежнему развивается в GPU-модели газа.
При полном пуле из 1800 визуальных частиц новое попадание вытесняет
35 самых старых остатков: свежий эффект не может исчезнуть целиком,
лимит остаётся тем же.
Огнемёт теперь покрывает каждый фактически пройденный порцией отрезок
перекрывающимися кубами со смещением и более тёплой, менее белой палитрой.
Сквозь твёрдое укрытие физическая порция не проходит; тест проверяет
распределение визуальных кубов вдоль сегмента. Копоть поверхности
ослаблена для фугаса 0,85 → 0,55, для беспламенной энергопушки — до
0,14; дымовые кубы светлее и прозрачнее.

Нативная запись при 1× времени и 30 кадрах/с: `out/content-check-shell-50`,
`out/content-check-flame-50b`, `out/content-check-mg-gun-50`. В записи
фугаса удар по стене случился на тике 91; вспышка видна на следующем
кадре, к тику 120 физический урон грунта уже закончен. В кадрах огнемёта
струя стала менее белой и менее регулярной, но две линии порций пока
ещё читаются отдельно; P-52 оставлен открытым. Длинная яркая фаза газа
после фугаса также требует отдельной настройки P-51. Запись пулемёта
с камеры стрелка показывает вспышку, но визуальную оценку трассера на
дистанции нужно повторить на шагоходе с двумя стволами.

Проверено: 334 теста `sim-core`, 113 тестов библиотеки `render`, 32 теста
окна `blast`; тесты фугаса и обоих стволов входят в эти числа. Эти
записи не являются замером гарантированных 120 FPS: сцена малая,
длительность короткая, P-45 остаётся открытым.
