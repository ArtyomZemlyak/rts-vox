## Что реально осталось

Все 12 EP актуализированы в [200](200-engine-performance-plan.md), все 28 WBPERF —
в [118](118-world-battle-performance-backlog.md). Большие EP не объявлены полностью
завершёнными; номер этапа 240 не равен закрытому EP. Внедрённые компонентный admission,
региональность и range filter повторно не ставятся в очередь.

1. **Цена точных запросов и удержанных данных.** Fine-search/поза/опоры, settled/rubble,
   повторные held groups и компактная валка. Persistent index F1/F2, запекание F5,
   overlap G1, prefetch G3 и sparse KnownCells G7 не дали приемлемого общего результата
   и отменены. Нужен иной механизм либо новое подтверждённое основание для повтора.
2. **Хвост приказа.** C5 достигнут для 17/18 машин, один паук без чистого start corridor
   ждёт fine search. Стартовая ротация доказана для неизменного набора желающих;
   динамический набор и полный input→visible ещё не приняты. Снижение бюджета узлов
   удлиняет отклик и не считается бесплатным ускорением.
3. **Полезный прогресс разрушения.** Реальный full pool, освобождение, wake/retry,
   фактический урон и работа обеих сторон; arrivals/completions/oldest age по источникам.
   Региональный обвал устранил старую причину, но сам по себе не доказывает дренаж
   всех очередей и предельную память при длительном огне.
4. **Весь product boundary.** Остальные terrain/occupancy/distant/effects readers,
   coherent export, bounded pending/upload, GPU-газ; затем owner вне кадра и lifecycle.
   P-74 зелёный не означает неизменяемость публичных полей BlastRange на уровне типов.
5. **Длительная приёмка.** Новый Windows headless/native baseline, 30 минут боя,
   20 reset/restart, save при незавершённой работе, memory attribution/transient peaks,
   разные seeds/оружие и visual/UX. Полная оружейная матрица и баланс остаются отдельными.
6. **Общий продукт и масштаб.** В выбранный BlastRange переносится экономика,
   стройка, реклейм, vision и legacy consumers; runtime team/owner/objectives,
   общий gun/battle контракт, модели из данных. Cap64 всё ещё есть; 5000 старого
   World не доказывают 5000 материальных машин. Мир 10 км — отдельный paged этап.

G4 внедряет pure chunk mapping с результатами по индексу и последовательным
применением. G2 измеряет число navigation workers на Linux/4 vCPU, но единого
пула не внедряет. G5 отклонён из-за недоказанной границы взаимодействия; это
не доказательство невозможности любого будущего безопасного island алгоритма.
Сумму первоначальных оценок 241 нельзя выдавать за доступные −7…−10 мс.

## Измерения и проверка

Канон `10-budgets.md`: **≤33 мс каждый headless tick боя 60 машин/900 тиков**,
**165 FPS / ≤6,06 мс каждый native кадр**. Среднее не доказывает выполнение max gate.
Профиль 240/241 позднего окна около 41–43 мс относится к Linux/4 vCPU и своим
коммитам (`d5aca4f`/`c2a0c00`); результат не переносится на Windows и более поздний
`0f4f13d`. 236/237, их hash, 11,4 млн NoRoom и 3436 заблокированных тиков — история
до смены правил. Новый FPS, новый полный бой и 30-минутный soak здесь не запускались.

Локально на `0f4f13d` выполнены:

- `cargo-local.ps1 test --release --locked --offline -p harness --test architecture --test docs`:
  **12 architecture + 3 docs, без падений**.
- `cargo-local.ps1 build --release --locked --offline -p render --bin blast`:
  **успешно**, `target/release/blast.exe`; запуск через `scripts/play-range.cmd`.
- Проверка полноты реестров, локальных новых ссылок, сохранности 14 QUESTION/defaults,
  unchanged runtime/data/scripts inputs и `git diff --check`: артефакты в
  `out/plan-audit-20261010/verification.json`. Это не повтор всех 1350+ функциональных
  tests из промежуточных Linux-срезов 240. Native окно не запускалось и не оценивалось.
