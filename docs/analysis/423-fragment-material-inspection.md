# 423 — Пипетка: материал обломка вместо грунта под ним

2026-10-26. Пользователь увидел «Материал · ID 7» при клике по обломку
у нагретой стальной плиты. В реестре полигона ID 7 — грунт с травой,
ID 3 — сталь (`data/range-materials.ron`). Это разные настоящие материалы;
внешний вид или происхождение рядом с плитой не делает грунт сталью.

## Причина

Пипетка выбирала рельеф, воду, юниты и связные падающие тела `bodies.list`,
но не отдельные `matter.debris.fragments`. Через видимый осколок луч
доходил до грунта. Дополнительно ID 7 отсутствует в палитре создаваемых
деталей лаборатории, поэтому инспектор печатал общее слово «Материал».

## Изменения

- Добавлен click-only запрос по действительным мешам фрагментов:
  `fragments/picking.rs`. Сначала AABB, затем пересечение треугольников.
  Используются те же маски, фаски, варианты насыщенных куч и трансформации,
  что при индивидуальном или пакетном отображении. Для сохранённых секций
  тела используется штатный `section_to_mesh` с исходным шаблоном.
- Побеждает ближайший результат до непрозрачного рельефа/воды/юнита или
  более близкого падающего тела. Пустоты маски и зазоры представления не
  считаются сплошным объёмом. Небольшой запас AABB покрывает округление
  Fx→f32, окончательный выбор всегда подтверждается треугольником.
- Выбор хранит ID фрагмента, поколение сцены и локальную точку попадания.
  При движении рамка следует за ним; изменение геометрии, удаление и reset
  сообщают о необходимости нового выбора, не подменяя владельца грунтом.
  Сдвиг по соседним мировым клеткам снимает привязку к осколку.
- Панель показывает фактический `f.material`, ID осколка, покой/движение,
  скорость, массу, число клеток и их размер. Свойства материала читаются
  из живого реестра симуляции. Тепло/влага грунта под куском не выдаются
  за данные фрагмента; отсутствие отдельного отслеживания подписано.
- ID 7 получает подпись «Грунт с травой» при осмотре. Состав палитры,
  нумерация материалов, физика, сохранения и свойства стали не изменяются.

Запрос треугольников выполняется только по нажатию пипетки. В обычной
отрисовке или во время пассивного наведения нет нового обхода осколков.
Обновление текста привязано к тику/поколению и ищет только выбранный ID;
на паузе повторная работа пропускается. Инспекция не меняет SIM.

## Проверки

Все пять `voxel_inspector` тестов прошли за 2.67 секунды:

- Настоящий стальной осколок над клеткой грунта ID 7 выбирается раньше
  нижележащего фрагмента и земли. Панель: «Сталь · ID 3», «Осколок #2».
  После движения позиция обновляется, после удаления показывается сообщение.
  Отдельный выбор грунта честно показывает «Грунт с травой · ID 7».
- Разреженная диагональная маска не ловит луч в пустом углу своего AABB;
  проверены поворот, масштаб 200 мм и предел дальности перед препятствием.
- Сохранённая стальная секция с собственным телом выбирается по её мешу.
- Прежние проверки соседних 10-сантиметровых клеток, нагрева, состояния,
  фокусировки, снятия выбора и неизменности state_hash остаются зелёными.

Тестовый конструктор панели теперь допускает готовую тихую сцену; проверки
пипетки больше не создают полный ИИ-бой ради чтения двух клеток. Это
изменение только тестового стенда. Проверка компиляции render прошла.

Подготовлена явная нативная fixture `RTS_LAB_CAPTURE_CASE=fragment-inspector`:
стальной фрагмент из обычного debris-admission над грунтом, выбор тем же
запросом, панель пипетки и близкая камера. Включается только при явно
запрошенном захвате, не затрагивает интерактивную сцену.


Release собран успешно. Нативный захват 3840×2160 проверен визуально:
в панели «Сталь · ID 3», «Осколок #1», покой, масса 7850 г, клетка 100 мм
и свойства стали. Лог: `FRAGMENT_PROBE id=1 material=3 label_steel=true`.
Нормальный выход 0, stderr пуст, сохранён `0000.png` в
`out/fragment-inspector-20261026/inspector-4k/`. Запуск скрытый, без фокуса,
30 FPS, BelowNormal, affinity=15, workers1/1/2; это проверка интерфейса,
не измерение FPS боя. Процессы сборки и захвата завершены.
