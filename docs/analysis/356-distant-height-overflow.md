# Пропавший рельеф после углубления грунта

21.10.2026. Скриншот пользователя: один локальный остров земли у шахты,
дальняя армия висит на фоне неба. Карта SIM загружена, отсутствует дальний
GPU-рельеф.

## Причина

read_layout поднимает исходную поверхность16 до80 из range-editor.ron.
Высота километровой карты192 становится256. overview::sync имел ранний
return при size[1]>255: выключался весь дальний рельеф. Компактный кодек
действительно хранил границы в8 бит и обрезал колонку take(255).
Локальное окно1280×192×1280 продолжало показываться, поэтому получался
отдельный остров, а юниты вне окна оставались видимыми.

Предыдущие проверки ядерного эффекта использовали снимки с высотой192.
Они не покрывали свежий запуск интерактивного полигона с новой глубиной.
В этой работе отдельно проверяется именно свежий запуск.

## Изменение

Снят запрет высокого мира. Колонки высотой≤255 сохраняют прежние четыре
u32 и формат. Более высокие используют четыре пары u32: нижняя и верхняя
границы u16 в первом слове; материалы тела/верхушки по4 бита и граница
верхушки u16 во втором. Общий WGSL-код декодирует оба варианта в одинаковую
пару, с которой работают видимый рельеф и raw_material для теней/эффектов.
Согласованы stride фоновой сборки, стартовой передачи и последующих правок.

Высоты не масштабируются и не округляются; сохранены кроны, крыши,
воздух между слоями и прежний выбор до четырёх отрезков. Параметры
локального окна и алгоритмы SIM не менялись. Формат сохранений прежний:
новые слова — временный GPU-буфер.

## Стоимость

Для высоких миров дальний массив занимает вдвое больше памяти: на
километровой карте2500² колонок это200000000 байт вместо100000000.
Максимальный GPU terrain buffer вырос с250 до350МиБ: локальный150МиБ,
дальний максимум200МиБ. Для низких миров фактический массив и передачи
сохраняют старый stride; резерв GPU общий. Горизонтальная детализация,
лимит4МиБ стартовой передачи на кадр и512 dirty columns прежние.
Старт высокого массива требует больше порций, а shader читает два слова
на отрезок. Отсутствие любого FPS-регресса этой работой не заявляется.

## Проверки

на255/256/448/16384 строках, последнем занятом вокселе, пустотах, крыше,
листве и границе материалов. Обзор строится из настоящего World/Columns
для256/448 с удалением выше255 и сравнивается с каждым мировым материалом.
Старый64-строчный путь и подтверждение отложенных upload-патчей сохранены.

Нативное воспроизведение Vulkan1600×900, свежий --range range-km.ron,
--skirmish18, --view overview --zoom6,31 кадр. Старая версия показывает
остров и зависшие маркеры, без строки DISTANT. Новая показывает сплошной
рельеф с лесом, дорогами и постройками. 6250000 колонок подготовлены
за2,43с; затем отображение полного массива разрешено. Общий --view map
