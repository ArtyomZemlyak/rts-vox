# Повторная проверка main: геометрия выпуска — 11.10.2026

## Исходный срез и результат

`git fetch origin` и `git pull --ff-only origin main`: новых коммитов нет,
`HEAD = origin/main = f806271`. Это продолжение [247](247-main-economy-pressure-review.md),
а не новые изменения другого агента. Проверен оставшийся P1 производства:
оплаченная линия без места выпуска повторяла дорогой поиск каждый тик.

Производство теперь использует точные маски занятых клеток из
`range_placement::Validator`, применяемые редактором и конструктором сцены.
В парном headless стенде закрытого выхода Tank стал **12,281 → 0,172 мс/tick**,
Strider **43,609 → 0,141 мс/tick**. Это специальная раскладка общего тика,
не FPS обычного боя. В штатных battle-world/range-km/skirmish-canister economy нет.

## Причина и исправление (ADR-678)

Прежний `free_spot` строил один пробный корпус, затем для каждого места
проходил всю AABB в порядке z/y/x: читал бит грунта и для породы заново
проверял `RangeUnit::solid`, включая преобразования координат корня и
сегментов. Пустые клетки коробки тоже участвовали. Конструктор корпуса
сам по себе стоил всего 0,13–0,16 мс (247), не объясняя 43 мс.

Теперь при создании сцены для видов из `production.producers` готовятся
обе ориентации общей маски. Повторные виды используют один кеш; без
заводов эти маски не строятся. В тике читаются только занятые клетки
и **текущая** битовая занятость мира. Результат «место заблокировано»
не кешируется. Ленивой сборки в тике нет: обращение требует готовую маску.

Пробный корпус по-прежнему определяет bounds и шаг сетки. Порядок
`(distance², linear grid index)`, рамка карты, коробки живых и погибших
юнитов, ориентация стороны и координаты выпуска прежние. Маска обрезается
по исходной сдвинутой AABB: усечение fixed-point около нуля нельзя
подменять переносом canonical bounds.

Маска — производная геометрия без нового игрового состояния. Формат и
версия снимка, стоимость, сроки, оплата, отмена, слоты и волны прежние.
Баланс, лимиты и правила сценариев не менялись.

## Регрессии поведения

1. **9 видов × 2 ориентации × 2 переноса = 36 случаев**, включая `[0,0,0]`
   с отрицательными границами. Точные множества клеток общей маски
   сравниваются с полным опросом свежего `RangeUnit::placed(...).solid`
   в AABB, включая сегменты.
2. Для Tank и Strider каждой стороны оплаченный заказ шесть тиков ждёт
   закрытый выход и сохраняется/восстанавливается побайтно. Поддержанный
   грунтом слой закрывает места; очередь снимает только клетки под
   гусеницами/стопами первого свободного места. В **тот же тик дренажа**
   юнит появляется в прежней первой позиции. Хеши непрерывного и
   восстановленного состояния, сторона, очередь, счётчики и материя
   совпадают; снимок после выпуска тоже восстанавливается.

Обе новые проверки прошли. Существующие проверки отмены, гибели завода,
лимита состава, очередей, волн, приказов и ИИ входят в повторный workspace.

Повторный release/locked/offline workspace: **1781 passed, 0 failed,
12 ignored, 126 suites**; `RUST_TEST_THREADS=2`, глобальный Rayon=4.

## Контроль редких поздних препятствий

В финальный диагностический бинарник добавлен `--sparse`: вместо полных
стен раскладка ставит узкие поддержанные грунтом столбики в поздней
занятой X/Z-колонке каждого доступного кандидата. Это только данные
геометрии; поиск и production остаются общими. Такой вход заставляет
просматривать почти всю маску, не довольствуясь первой занятой клеткой.
Методика 30+120, 4/4/global4, control/active/active/control прежняя.

| Продукт | Control, среднее двух тиковых средних, мс | Active, мс | Active p99 двух запусков, мс |
|---|---:|---:|---:|
| Tank | 0,0571 | **3,1121** | 3,525 / 3,777 |
| Strider | 0,0331 | **1,2703** | 1,587 / 1,579 |

Очередь/оплата/баланс/отсутствие выпуска проверяются каждый тик; active-a
прошли byte-roundtrip и 30 replay ticks. Повторные tick150-хеши одинаковы:
Tank `51571b7c0a9eed73`, Strider `4f124a855047a020`; replay180 —
`0a331fd3da4e53ef` / `42a67651931ee4a0`. **Before на этой геометрии не
измерен**: это контроль остаточной стоимости, не новый коэффициент ускорения.
Одна линия проходит 33 мс, но стоимость многих линий не ограничена общим
бюджетом и этой серией не квалифицирована. P1 общей приёмки не закрывается.

Финальный бинарник дополнительно повторил сплошную стену/Strider:
0,173 мс/tick, прежние hash150/180, сохранение tick150 побайтно совпало
со снимком основной A/B-серии. Новый режим изменил только diagnostic bin,
runtime геометрии тот же. Артефакты — `sparse-*.csv/log`, `final-solid.*`.

## Границы результата и оставшийся план

Закрыт повторный pose-hit обход пустой части AABB. **Общая приёмка поиска
выхода частичная**: сплошная порода обнаруживается первой занятой клеткой,
редкие препятствия требуют читать большую часть маски. Перебор мест и
клеток пока без общего бюджета/continuation; коробки и конструктор probe
повторяются каждый тик. Маски занимают память и время создания/загрузки
сцены; эти затраты не входят в timed tick основной серии.

Следующий срез: бюджет действительной работы поиска, включая чтение клеток,
детерминированное продолжение и точная инвалидация после изменений мира,
состава и поз. Оплата, заготовка, очередь и порядок сохраняются. Приёмка:
поздние редкие препятствия, много оплаченных линий, свободный выход,
снятие/повторное появление препятствия, отмена/гибель, save/replay, стоимость
подготовки геометрии. Состав по-прежнему ограничен 64 слотами.

P1 пустой копки 64/r32 (~83 мс), P2 объёмных единиц тел из 246, линейный
проход/плотный реклейм из 247 открыты. Для обычного боя EP-08/03/07/10/04/06
прежние: coarse continuation, владелец симуляции вне кадра, dirty publication,
устойчивый прогресс очередей. 165 FPS/p99, 30-минутный бой, 20 reset/VRAM
и 5000 юнитов не закрыты. Последний штатный native профиль — прежний 247,
не новый результат этого патча.
