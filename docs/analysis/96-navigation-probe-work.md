# Повторные проверки грунта в навигации

24.09.2026, ADR-403, P-45/P-5/P-63. База — `7a8bdd9`.

## Изменения

- Поиск сначала проверяет другие корпуса. Если положение уже запрещено,
  грунт под ним не сканируется. Логическая проверка по-прежнему расходует
  бюджет, поэтому ранний отказ не увеличивает работу поиска за тик.
- После отказа по уклону, завалу или первому столбцу выше днища поиск
  не продолжает обход остальных столбцов. Высоты опор остаются точными;
  у допустимой позы полностью считается растительность для стоимости пути.
  Исполнитель движения сохраняет полный подсчёт пересечения с грунтом:
  он нужен для выхода из уже занятой позиции.
- Интерполяция опоры не читает соседей с нулевым весом. На пересечении
  линий сетки нужен один столбец вместо четырёх, на линии — два. Для
  дробных координат порядок арифметики фиксированной точки прежний.
- Неизменившиеся X, Z и курс корпуса используют полный ответ о грунте,
  уже вычисленный в этом же тике. Между тиками ответ не сохраняется;
  подвеска, падение и контакты не пропускаются.

Эвристика маршрута, физические пределы, бюджет поиска и формат снимка
не менялись. Диагностические счётчики сканирования могут уменьшиться.

## Отвергнутый вариант

Проверена оценка расстояния с разной ценой прямого и диагонального
шага — 10 и 14, как в графе. Она прошла тесты навигации и 176 рельефных
сочетаний, но ухудшила длинный проезд среди патрулей: прибытие на тике
6012 вместо 5428. Вариант отклонён; чувствительность разъезда и
продолжения частичных маршрутов остаётся в P-5/P-63.

изменений дали 1,543 мс в среднем — около 1 % от базы.

этого стенда):

```powershell

```

Наиболее дорогой хвост оказался в `collapse_resolve`: p99 16,670 мс,
максимум 25,418 мс; `collapse_promote` — p99 2,197 мс, максимум 7,009 мс.
Стадия `motion` дала p99 5,090 мс. Статистика отдельной фазы считается
по её вызовам; фазы обрушения выполняются не каждый тик. Следующая
цель P-45 — расчёт обрушений при валке растительности вдоль маршрутов.
Это отдельный стенд с другим пресетом, его хеш не сравнивается с
`bench_drive`; журнал — `final-phases-6500.txt`.

## Проверки

- 77 тестов навигации. Новые проверки сравнивают 3136 полных и
  сокращённых проб: отказ, высоты, уклон, завал, полный подсчёт валки
  для допустимых поз. Отдельно проверены 567 положений интерполяции,
  включая один бит дроби, границы мира, неровный грунт и обломки.
- Ранний отказ по корпусу расходует ровно один логический запрос,
  не читает грунт этой позы; после освобождения прохода проверка работает.
- 26 тестов движения. У стоящих танка и шагохода удаляется грунт под
  всеми опорами: на следующем тике новые высоты уже видны, начинается
  падение, затем машина достигает нового дна без горизонтального сдвига.
- Все 176 рельефных сочетаний с прежними порогами, 19 тестов сохранения,
  четыре golden-теста с прежними эталонами. Два диагностических теста
  рельефа остаются `ignored`.
- Побитовый повтор полной сцены после загрузки незавершённого поиска;
  `clippy -p nav -p sim-core --all-targets -- -D warnings`.
- Форматирование и релизные сборки стендов и нативного окна `blast`.
