# Объединение материалов больших областей

24 октября 2026. ADR-803. Изменён только способ сборки консервативного
набора World::material_candidates. Размер вокселя, физика обломков,
радиусы, прочность, квоты, частота SIM и форматы сохранения прежние.

## Механизм

Раньше каждый пересечённый изменённый чанк дописывал свою палитру в Vec,
после чего весь список повторов сортировался. Теперь после накопления
больше512 записей палитр ID объединяются через временный битовый набор
всех65536 u16 значений (8 КиБ). Короткие списки сохраняют прежний
append/sort без дополнительного буфера. Размер области сам по себе
не включает битовый путь. Указатели соседних чанков читаются непрерывными
срезами строк вместо отдельного вычисления индекса каждого чанка.
Возвращаемый отсортированный набор точь-в-точь прежний.

Нет кеша, инвалидирования, записей в состояние мира и новых настроек.
Старые неиспользуемые записи палитр сохраняются, неизвестный генератор
даёт прежний None. Не вводится приближение материала или разрушений.

## Изолированный замер

Добавлен ручной ignored measure_material_candidate_union с независимым
старым append/sort oracle в том же бинарнике. Генератор и палитры берутся
из одного неизменяемого World. Это замер конкретной операции, не FPS игры.
Проверочный мир512×32×512 имеет256 изменённых чанков с повторяющимися
палитрами. Замер final-v2-candidate-bench выполнялся без фоновой сборки.

| Палитра | Область | Старый oracle, нс | Итог, нс |
|---|---|---:|---:|
|8 ID|9×9×9|68|62|
|8 ID|64×32×64|200|189|
|8 ID|96×32×96|388|358|
|8 ID|512×32×512|5099|1849|

Большая область быстрее примерно в2,8 раза на короткой палитре и12 раз
на богатой. Самый маленький богатый запрос получил небольшой расход
396→425 нс; это не универсальное ускорение всех запросов. Тайминг ручной,
не порог CI. Высокие ID распределены вплоть до65535.

## Предварительный вариант

Первый вариант включал битовый набор по числу чанков>8. Он ускорял
широкие запросы, но короткая палитра8 ID на96×32×96 дала379→669 нс.
Поэтому критерий заменён на фактический объём накопленных палитр>512.
Логи after-candidate-bench/final-candidate-bench относятся к ранним пробам.

after-game.exe/after-battle.exe и after.csv/log содержат этот первый
вариант. Его бой1600,nav8/physics4/Rayon4 дал9826,94 мкс/тик,
P9948963 мкс, максимум78868 мкс, hash af3a8a86c556f10d. Эти цифры
не подменяют итоговый замер. Исходный headless для сверки —
out/optimization-385/before-battle.exe и before.csv/log, hash тот же.

## Проверки

181 voxel-тест прошёл,1 ручной тайминг пропущен. Новый oracle сравнивает
широкие и узкие запросы на частичных границах чанков, смещённые области,
повторы генератора и высокие ID вплоть до65535. Существующие тесты проверяют
committed overlays, ожидающие правки, восстановление snapshot, неизвестный
генератор и неверные границы. Они сохраняют точный состав и fallback.

Артефакты находятся в out/optimization-386. Исходная игра — before-game.exe.

Итоговый критерий>512 прошёл повторно181 voxel-тест, golden600 с прежним
хешем e2a540edb6a0dcc0 и3 snapshot-теста. Документационные3 и
архитектурные12 тестов прошли; git diff --check прошёл. Полная suite
остальных крейтов не запускалась. Итоговые логи final-voxel-v2-tests,
final-golden-snapshot-tests, final-docs-tests, final-architecture-tests.

## Итоговый headless

accepted-battle.exe, world/ai-vs-ai,1600 тиков,nav8/physics4/Rayon4,
без фоновой сборки. hash af3a8a86c556f10d совпал с исходным.
Средний тик9970,32 мкс против9912,40 в контрольном запуске385;
P9948339 против49924 мкс; максимум78588 против79887 мкс.
Среднее время всего тика не улучшилось; небольшие различия хвоста
одной пары не доказывают устранение рывков. Это ограничение итогового
выигрыша: сильно ускорен отдельный запрос, но он не доминирует в этом бою.
Старый headless-контроль взят из385 и выполнен раньше, поэтому его
тайминги не подменяют свежую оконную пару этой задачи.

## Свежая оконная пара

RTX5090, Vulkan. Развёрнутое окно на4К-мониторе: запрошено3840×2160,
фактическая клиентская область3840×1949. Сохранённые настройки,
world-battle/ai-vs-ai,60 секунд/1200 тиков,nav8/physics4/Rayon4/compute4.
Оба запуска без диагностических наблюдателей и параллельной сборки,
с неизменным контекстом камеры; valid/acceptance eligible.

| Метрика | До | Итог |
|---|---:|---:|
|Средний FPS|92,9|93,0|
|Минимальный мгновенный FPS|9,1|9,3|
|Максимальный мгновенный FPS|644,0|522,6|
|1% low FPS|19,2|19,4|
|P99 кадра, мс|35,428|35,169|
|Самый долгий кадр, мс|109,453|107,046|

Общий FPS практически прежний. Малая разница хвоста одной пары не
доказывает устранение рывков. Ускорение подтверждено для конкретной
операции объединения материалов, не для всей игры. Мгновенный максимум
не является устойчивой частотой кадров. Крупные пики остаются.

Итоговый SIM hash обоих оконных прогонов d2cae11030043979, часы симуляции
успевают (realtime ratio0,9998/0,9997). Изменение не затрагивает shader,
геометрию и данные; новый визуальный capture для него не выполнялся.

accepted-game.exe и рабочий target/release/blast.exe совпадают по SHA-256:

чанков и не подменяют итог с критерием>512 записей палитр.
