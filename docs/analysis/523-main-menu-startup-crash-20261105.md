# 523 — Вылет до появления главного меню

5 ноября 2026. Регрессия после `003e31d`.

## Воспроизведение и причина

Проверены настоящие ярлыки рабочего стола, включая бинарный разбор `.lnk`:
`Полигон.lnk` запускает `scripts/play-range.cmd` без дополнительных аргументов;
второй ярлык вызывает тот же файл с `-Build`. Далее `play-range.ps1` запускает
актуальный `target/release/blast.exe` с `--weapon energy --chassis tank
--range data/range-km.ron --drive`. Ярлык не сломан.

Обычный путь без `--shots` воспроизводит падение в
`bevy_pbr-0.19.1/src/atmosphere/environment.rs:116`:
`prepare_atmosphere_probe_bind_groups` вызывает `unwrap()` для отсутствующего
GPU-буфера. Меню выключало все 3D-камеры, но генератор окружения атмосферы
продолжал готовить свои группы привязок без активного 3D-вида.

Предыдущая проверка нативными снимками не покрыла этот случай: при `--shots`
одна 3D-камера намеренно оставалась активной. Поэтому снимок меню успешно
сохранялся, хотя запуск пользователя без съёмки падал. Логи воспроизведения:
`target/startup-normal-crash.err` и `.out`.

## Исправление

- Во время меню основная камера остаётся активной и выводит изображение в
  один переиспользуемый буфер **32×32 вне окна**, а не в полный экран.
  Атмосфера получает корректные буферы; обычный мир не рисуется в окно.
  Симуляция по-прежнему приостановлена, вспомогательные 3D-камеры выключены.
- При закрытии меню восстанавливается исходный `RenderTarget`, включая
  обычный вывод в окно. Повторное открытие переиспользует тот же маленький
  буфер; новые изображения при каждом переключении не создаются.
- Путь съёмки сохраняет прежний оконный рендер. Версии зависимостей и
  содержимое реестра Cargo не изменяются.
- Лаунчер сохраняет stdout/stderr каждой игровой сессии в уникальные файлы
  `out/launch-logs/<UTC-время>.out.log` и `.err.log`.

## Защита от повторения

`scripts/test-menu-startup.ps1` проверяет **путь без `--shots`** с теми же
основными аргументами, что у ярлыка. Для фонового запуска и автоматического
завершения используется короткое штатное профилирование, без GPU/core-трасс,
в неактивном окне 3840×2160, с лимитом 30 FPS. Проверяется код завершения
и отсутствие panic/validation errors. Есть тайм-аут и остановка только своего
процесса. Cargo/Rayon ограничены двумя потоками, процессы — BelowNormal,
affinity=5. Это проверка запуска, не замер FPS боя.

Семь проверок `frontend::tests` прошли (119,46 с). Включены переходы в бой,
режим наблюдения, полигон и лабораторию, возврат после ошибки, пауза, курсор
и восстановление оконного вывода после маленького служебного буфера.

Нативный запуск исправленной review-сборки без съёмки прошёл в 4К:
`target/menu-crash-smoke-review.out`, код 0; stderr
`out/menu-startup-check/20261105-021749-311.err.log` пустой.
