# Отсечение пустых лучей газа

24 октября 2026. Продолжение382. Размер кубов, скорость юнитов,
SIM20 Гц и правила разрушений сохранены. Изменения только в рендере.

В диагностическом30-секундном бою ИИ с сохранёнными настройками, RTX5090,
Vulkan, развёрнутым окном на4K (клиент3840×1949) сумма газовых проходов
составила6,64 мс на кадр с GPU-сэмплом. Предварительный пропуск шума
заведомо нулевой копоти дал6,56 мс; это слишком мало для основного решения.
Оба диагностических прогона не используются как ordinary FPS.

Основное изменение — консервативный габарит потенциально видимых газовых
клеток. GPU редуцирует поле48³ после изменения; новая память24 байта на
область. Из исходного значения считается верхняя оценка плотности, порог
0,06 вдвое меньше минимального порога видимости0,12. Габарит расширен на
поддержку интерполяции и два ребра отображаемой клетки. Пропускаются
только целые лучи, которые заведомо не пересекут видимый газ. Для остальных
не меняются DDA, начало и предел360 шагов. Освещение/копоть поверхности
применяются до отсечения. Readback в игре отсутствует. Контракт — ADR-799.

Проверки GPU:5/5, включая реальную редукцию пустого, разнесённого,
граничного, исчезнувшего поля и значения между консервативным и видимым
порогами. Полные shader modules и прежние тесты решателя также проходят.
Первый запуск выявил неверное явное преобразование u32→f32 в конструкторе
вектора; оно исправлено до запуска новой версии окна.

Артефакты экспериментов и замеров: `out/optimization-383`.

Первый ordinary A/B:60 секунд, world-battle/ai-vs-ai,62 юнита,
nav8/physics4/Rayon4/compute4, сохранённые настройки. VSync отключён;
камера неподвижна. Реальный клиент3840×1949 при развёрнутом окне на4K.
