# Материал выбранного объекта в лаборатории, 25.10.2026

Проблема: палитра меняла `Recipe.material`, а он задавал материал
параметрической стальной пластины. Любая такая смена восстанавливала сцену.
Для уже размещённых деталей существовала отдельная кнопка; она работала
только для элемента с одним блоком. Для составного здания была выключена,
а заголовок «Материал образца / новой детали» не объяснял эту разницу.

## Что изменено

- Выбор палитры хранится отдельно от применённого рецепта стенда:
  `Workspace.selected_material`, стабильный ID, необязательное поле старых
  сцен. Выбор больше не меняет геометрию или физику и не сбрасывает опыт.
- Во вкладке «Материал» видны имя цели и её текущие материалы. Доступна
  палитра кнопок по именам, выделяется выбранный материал.
- «Применить» меняет выбранный блок или все непустые блоки составного
  объекта. Воздушные вырезы, остальные объекты и библиотечный оригинал
  сохраняются. Для одной части остаётся разбор сборки.
- Когда объект не выбран, отдельной целью может быть параметрический стенд.
  Он меняется только явным применением. Форма/толщина/множитель прочности
  подписаны как параметры отдельного стенда и отключены, когда его нет.
- Нажатие на объект в сцене и на строку состава использует одинаковый выбор.
  Открытая вкладка материала сохраняется при выборе другого объекта.
- Если после размещения из библиотеки сразу открыть «Материал», размещение
  завершается и редактируется только что поставленный объект. Неразмещённая
  копия и новый каталоговый preview не редактируют прежнее выделение.
- Новая деталь и летающая кисть читают выбранный материал сразу. Preview
  детали обновляется без пересоздания сцены; выбор палитры не инвалидирует
  сравнение опытов A/B как физическое изменение.
- Числовые свойства прочности, плотности и плавления используют материал
  палитры и явно подписаны как изменение типа материала во всей сцене.
  Они не являются индивидуальными свойствами только выбранной геометрии.
- Сцена сохраняет выбор материала. Старые файлы без этого поля читаются,
  для выбранного объекта при загрузке подставляется его текущий материал.

Материалы шаблонных боевых юнитов пока не заменяются этим инструментом
блоков. Для такого выбора интерфейс объясняет причину; свойства выбранного
типа материала можно менять общим механизмом. Разрешать кнопку, которая
меняла бы только невидимый стенд, интерфейс больше не пытается.

## Как пользоваться

1. Выбрать объект в сцене или слева в составе сцены.
2. Открыть «Материал», проверить строку «Цель» и нажать имя материала.
3. Нажать «Применить».

Для изменения только одной части здания: «Объект» → «Разобрать сборку»,
выбрать деталь и повторить шаги. Применение геометрии восстанавливает
исходную сцену опыта, как остальные операции конструктора.

стенда и каталога, выбор числовых свойств по нужному материалу, обновление
preview новой детали, сохранение сцены, запрет правок шаблонного юнита и
защита от редактирования старого выделения при размещении копии.
