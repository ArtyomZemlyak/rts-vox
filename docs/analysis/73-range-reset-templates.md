# Повторная сборка юнитов при сбросе полигона

24 сентября 2026, P-49, ADR-380. После ускорения восстановления мира
полный сброс 100 повреждённых чанков всё ещё занимал 14–15 мс.
Замеры делались на прогретой release-сборке той же километровой карты;
разделение фаз добавлено в `bench_range_reset`.

| Фаза повторного сброса | До | После |
| --- | ---: | ---: |
| Проверка размещения | ~2,0 мс | ~2,0 мс |
| Восстановление мира и подготовка его генератора | ~0,3 мс | ~0,23 мс |
| Инициализация слоя опор | ~1,8–2,0 мс | ~1,8–2,0 мс |
| Создание девяти юнитов | ~8,0 мс | ~1,7–2,0 мс |
| Полный сброс | 14–15 мс | 8,1–8,9 мс |

Раньше каждый экземпляр заново рисовал объём ванильного танка или
шагохода. Теперь исходное тело каждого вида создаётся один раз на
процесс; `RangeUnit::of_kind` получает собственную копию. Повреждение
одного тела не меняет ни другой экземпляр, ни шаблон. Так сохраняется
обычный путь урона и снимков. Индекс авторского рельефа, построенный
при проверке размещения, передаётся в новый генератор мира вместо
повторного построения. При смене размера карты остается полный путь.

Проверка настоящего окна: `profile-range.ps1 -Scenarios actions -Seconds
20`. В профиле до правки действие расстановки занимало 19,509 мс
в фазе `simulation_input`, повторная пересборка — 19,469 мс. После
правки — 12,673 и 15,722 мс. Для всего кадра: p99 5,594 → 5,590 мс,
максимум 29,805 → 22,627 мс, кадры выше 8,33 мс — 22 → 23.
Величина общего максимума зависит от соседних кадров и не является
гарантированным выигрышем каждой перестройки. После неё наблюдалась
подготовка рендера до 10 мс; визуальное обновление и синхронизация
теперь важнее для P-49, чем копирование шаблонов. Холодный запуск
по-прежнему занимает секунды и отдельно не оптимизирован.

Воспроизведение из корня репозитория:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/cargo-local.ps1 build --release -p sim-core --bin bench_range_reset
target/release/bench_range_reset.exe
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/profile-range.ps1 -Scenarios actions -Seconds 20 -Output out/performance/reset-template-actions
```

Нативный CSV и лог этого прогона — в
`out/performance/reset-template-actions`. Тесты проверяют независимость
повреждаемого тела экземпляров и равенство сброшенной сцены свежей,
включая будущие тики и хеши. Порог 120 FPS для каждого кадра ещё не
достигнут; P-49 и P-45 остаются открыты.
