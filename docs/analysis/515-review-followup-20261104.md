# Продолжение ревью main — 4 ноября 2026

Продолжение отчёта [514-main-review-20261104.md](514-main-review-20261104.md).
Проверяется тот же main `a3b7445` с локальными исправлениями; новые коммиты
с сервера в этом цикле не подтягивались. Изменения предыдущего цикла сохранены.

## Исправления движка

1. **Ручной полёт «Скобы».** Общий обработчик движения раньше полностью
   пропускал живого строительного дрона, оставляя движение автомату доставки.
   Добавлен отдельный ручной контроллер на существующем состоянии привода:
   ускорение, поворот, торможение после отпускания управления, сохранение высоты.
   Скорость ограничена характеристиками шасси. Наземный поиск пути для него
   не запускается. Вертикального ручного управления этот патч не добавляет.
2. **Автомат доставки перестал перебивать пилота.** Во время ручного управления
   и последующего торможения сохраняются груз, стадия задания и резервирование.
   После остановки автомат может продолжить работу.
3. **Защита от пролёта через препятствия.** Проверяется фактическая занятая
   область корпуса, включая форму с грузом. Перемещение и поворот проверяются
   промежуточными позициями против земли, границ мира и корпусов юнитов.
   Число проверок ограничено 128; чрезмерное перемещение из редактированных
   характеристик отклоняется. Проверка консервативная: использует объёмные
   ограничивающие коробки, а не точные столкновения всех вокселей.
4. **Снимки состояния сохраняют форму дрона.** Открытый, сложенный и загруженный
   корпуса имеют разную геометрию. Раньше восстановление начиналось с обычного
   корпуса, что давало расхождение при ручном полёте с грузом и мешало
   восстановлению повреждений клеток, существующих только в загруженной форме.
   Необязательная секция 77 сохраняет вариант до чтения повреждений;
   восстановление источников обломков использует ту же форму.
5. **Проверка учёта материи при загрузке учитывает смену формы.** Изображение
   груза не должно создавать дополнительный запас материала корпуса: груз
   учитывается своим контейнером, исходный запас корпуса сохраняется.
   Это исправление восстановления, а не переработка физического представления
   груза и его взаимодействия со всеми видами оружия.

Новые метаданные проверяются на допустимый класс юнита, номер формы,
количество записей, порядок и уникальность индексов, выход за границы и
обрезанные данные. Старые снимки без секции 77 читаются; для неповреждённых
дронов загруженная/возвратная форма восстанавливается по заданию. Точную
историческую форму повреждённого дрона старый файл не содержит, поэтому
полностью восстановить такую информацию задним числом нельзя.

## Уточнение устаревших тестов

Эти изменения отделены от исправлений игрового поведения:

- Проверка неизвестного материала использовала ID 10, который уже занят
  песком. Теперь используется заведомо неизвестный `u16::MAX`; повреждённые
  идентификаторы также проверяются в тесте формата.
- Проверка восстановления старого плавления теперь восстанавливает одинаковую
  конфигурацию стенда с обеих сторон сравнения.
- Смешанный опыт песка и камня считает материал и в мире, и в сохраняющем форму
  падающем теле. Камень не обязан перестраиваться в неподвижную сетку, чтобы
  считаться сохранившимся. Сохранение количества песка/камня и повторяемости
  по-прежнему проверяется.
- Проверка торможения задаёт начальную скорость относительно установленного
  тормозного ускорения. Прежняя скорость была меньше торможения за один тик,
  поэтому мгновенная остановка в этом стенде была допустима.
- Старые проверки резервного разрушения/осколков явно отключают конкурирующий
  зернистый/вязкий решатель только внутри соответствующих стендов.
  Настройки песка и расплава в игре не менялись; современные проверки
  свободного падения, смешанной сцены и гравитации тоже выполнены.
