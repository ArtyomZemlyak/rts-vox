# Групповое подтверждение грунтовых разрушений

24 октября 2026, продолжение390, ADR-807.
Артефакты: `out/optimization-391/`. Изменён SIM burst adapter.
Размер вокселя, SIM20Гц, квоты, радиусы, энергия и данные баланса прежние.

## Причина и изменение

В диагностике388 тяжёлый tick911 содержит около11,6мс claims и около
19,1мс read_ground. Эти вложенные этапы не складываются с родительскими
apply/frontier вторично. Итерация сокращает работу заявок и подтверждения,
а не утверждает, что полностью устраняет пик чтения материалов.

В claim_voxel_checked дерево группы и дерево клетки ранее проходились
повторно при вставке после проверки. BTreeMap Entry сохраняет найденную
позицию. Отказы проверяются в прежнем порядке; отказ не создаёт запись.

В confirm_reserving из каждой группы последовательно вычитались биты,
а резерв компонент пересчитывался после каждой клетки. Между удалениями
этого атомарного этапа резерв не использует ни допуск новых заявок,
ни создание обломков. Теперь фиксируется исходное число компонент каждой
затронутой группы, снимаются все её подтверждённые заявки и единожды
считается итоговая связность. Общий резерв перед созданием обломков:
прежний минус исходные компоненты затронутых групп плюс итоговые.
Пустые группы удаляются. Несостоявшаяся копка освобождает заявку тоже;
удалённая перемычка может разделить остающиеся части и увеличить резерв.

Порядок completed, заявок, групп и создания фрагментов прежний.
Распыление, контейнеры, энергия и сохранения не меняются.
Постоянный кэш связности или дополнительное игровое состояние не вводится.

Сырые dispatch-probe логи относятся только к тестовой гипотезе,
а не к выпущенной игре и не к обычному FPS.

## Проверки

Независимый старый admission oracle сравнивает ответы, резерв, группы,
save bytes и очередь правок для всех сторон1–4, нулевого/малого/большого
резерва, повторов, рамки и внешних клеток. Новый confirmation oracle
сохраняет прежние поэлементные обновления.96 сочетаний стороны1–4,
пула0/1/32/1024, пакета1/13/1024 и дополнительного резерва0/8 сравнивают
группы, резерв, распыление, save bytes фрагментов и материи после каждого
пакета. В потоке есть успешные копки, воздух, замена материала,
посторонние правки и повторные уведомления.

108 burst и13 nuclear проверок прошли; ручные probes вынесены отдельно.
Полная SIM suite не перезапускалась; открытые отказы аудита389
этим срезом не объявляются исправленными.

## Измерения

Стенд probe_ground_claim_pipeline отделяет выдачу заявок от подтверждения,
без генерации чанков внутри измерения. На входе40960 клеток; три серии
каждой версии, по восемь прогретых повторов. Не является полным тиком.

примерно на27мкс; суммарный pipeline остаётся близким по времени.
