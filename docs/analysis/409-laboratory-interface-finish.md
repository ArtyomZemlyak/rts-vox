# 409 — Доводка интерфейса лаборатории

## Основание

Свежие нативные снимки `out/laboratory-interface-finish-20261025/before-*/0000.png`:
1. Источники, 3840×2160: повторяющиеся вертикальные поля XYZ вытесняли цель;
   маркеры показывались, но клик по ним не выбирал источник.
2. Оружие и ввод, 3840×2160: имя источника находилось после списка воздействий;
   не было видимых кнопок применения/отмены. Ошибка проверки закрывала поле.
3. Привязанный источник: список говорил только «юнит», без имени и положения
   действующего ствола. Вход без лаборатории проверен отдельно по журналу запуска.

## Изменения

- Выбор источника по кубу-маркеру в режиме V; попадание проверяется в экранных
  координатах с постоянным радиусом 14 логических пикселей, не по вокселям.
  При совпадении выбирается ближайший к курсору маркер, затем меньший индекс.
  Проекция и просмотр не изменяют SIM. Для позиции маркера и инспектора
  используется один источник данных, включая действующий ствол юнита.
- Строки XYZ вместо шести вертикальных блоков с повторяющимися кнопками.
  Свободные координаты подписаны отдельно от текущего положения ствола.
- Имя источника и готовность к пуску вынесены вверх вкладки оружия;
  добавлены переходы между источниками и настройками оружия.
- Панель «Применить / Отмена» закреплена под прокручиваемым инспектором.
  Ошибка сохраняет ввод, выделяется цветом и объясняется текстом. Ctrl+A
  выбирает всё значение. Десятичная запятая поддерживается. Целочисленные
  параметры отклоняют дробь, мощность допускает точность до 0.001×.
- Смена объекта, материала или источника возвращает инспектор наверх;
  изменение значения не сбрасывает прокрутку.
- Кнопка паузы показывает «Продолжить» в остановленной симуляции.
  Быстрый старт описывает источники, привязку, настройки карты и ввод.

## Ограничения проверки

Снимки подтверждают расположение, читаемость и видимость команд, но не полную
доступность с клавиатуры или экранным диктором. Для числовых полей есть Enter,
Esc и Ctrl+A; сквозная навигация по всему редактору клавишей Tab не добавлялась.
Новых зависимостей, игровых тиков, изменения размера вокселя и работы
в симуляционном ядре нет. Радиус клика — параметр редакторского UI.

## Проверки

`cargo check -p render --bin blast -j4` прошёл. Целевой набор
`cargo test -p render --bin blast --release laboratory -j4`: 23/23,
121.08 с; компиляция 3 мин 22 с. Один поток тестов, BelowNormal,
affinity 15, RAYON_NUM_THREADS=4. Новые проверки:
- ошибка размера и дробь в целочисленном поле не меняют снимок мира,
  оставляют текст для исправления; отмена очищает ошибку;
- Ctrl+A заменяет всё значение, последующее применение меняет только
  настройку выбранного источника;
- попадание в маркер сохраняет экранную чувствительность при трёх масштабах,
  не меняет SIM и не выбирает источник при промахе;
- смена источника возвращает прокрутку наверх;
- построение и синхронизация полного UI включает новые поля и инфоблоки,
  проверяет отсутствие конфликтов Bevy-запросов.
После набора тестов добавлено только отсечение переполненного текста в поле
и уточнена подпись свойств материала; повторный `cargo check` прошёл.

Первый визуальный проход: девять скрытых запусков с лимитом 30 FPS,
Vulkan, 1 physics/nav worker, 2 compute workers, BelowNormal, affinity 15.
Все exit=0, пустой stderr. Проверены 4K источники, ввод, привязка, ошибка,
помощь; 1600×900 источники, ввод, помощь; обычный полигон проверен как запуск без захвата изображения.
Кнопки применения/отмены видны при 1600×900, ошибка остаётся текстом
рядом с действиями. Быстрый старт целиком помещается в окно.
По сравнению одинаковых источников найдено избыточное число строк над XYZ:
последняя доводка уменьшает интервалы этой вкладки, объединяет действия
привязки в строку и переносит пояснение под координаты. Кнопки называются
«Позиция», «К юниту», «Точка»; «Оружие» и «Цель» ведут к настройкам.
После этой правки `cargo check` прошёл; логика взаимодействия не менялась.


## Результат визуальной проверки

1. Выбор и координаты источника — исправлены: в 4K вся вкладка источников,
   включая обе строки XYZ, помещается без прокрутки при двух источниках.
   В 1600×900 основные команды видны сразу, координаты доступны прокруткой.
2. Привязка к юниту — показаны имя танка и текущая точка ствола; сохранённая
   свободная точка подписана отдельно. Маркер совпадает со стволом.
3. Ввод числа — кнопки применения/отмены видны в обоих разрешениях, ошибка
   показана текстом и цветом. Имя источника и готовность расположены сверху.
4. Помощь — полный текст и кнопка закрытия помещаются в 1600×900.
5. Вход в обычный полигон — exit=0, пустой stderr, без захвата изображения.
