# 488 — Geometry из Memo::Input в merge groups: отклонено

3 ноября 2026. Артефакты: `out/optimization-488/`, не новый ADR.

## Гипотеза

`Memo::current` уже содержит `input.geometry`, но merge groups вызывал `Geometry::of`
повторно. Прототип хранил memo index в shard и читал геометрию из current. Размер записи
не увеличивался, self-referential scratch не использовался, donor order не менялся.

## Проверки

200 тиков и две полные серии по1600: все36 нетайминговых полей каждого тика совпали.

## Производительность

| Пара | Mean tick | Позднее окно | `debris`, mean |
|---|---:|---:|---:|
|1, после→до|25,802→25,788 мс (−0,06%)|35,620→35,731 мс (+0,31%)|9,029→9,082 мс (+0,59%)|
|2, до→после|25,672→25,849 мс (+0,69%)|35,431→35,777 мс (+0,98%)|9,043→9,177 мс (+1,49%)|

Сводно mean 25,737→25,818 мс (**+0,32%**), позднее окно 35,526→35,754 мс
(+0,64%), `debris` 9,036→9,130 мс (+1,04%). Дополнительная индексация memo стоит
дороже повторного `Geometry::of`.

## Решение

Прототип отклонён и откачён, исходный `Geometry::of` восстановлен. ADR-834 shard
scratch сохраняется. Geometry-reuse направление закрыто.
