physics1 и8CPU дали одинаковые первые64tick-hashes. Сравнение текущих256
с полным G reference выявило первый differing tick112. Оба снимка112
прочитаны текущим restore_observed с byte-for-byte roundtrip. Первый
различающийся байт840795 находится в unit_motion(unit45), kind Strider.

Причина: новая передача preview cadence в исполнитель применялась при
nominal fit ко всем ходячим. Она требовалась лишь новому профилю Commander,
но сохраняла ранний cadence до позднего выбора движения у Strider.
Область применения ограничена guided_biped; существующая передача cadence
при реальном support wait оставлена. Проверки и физические пороги не
ослаблялись, Canonical hash не подгонялся.
