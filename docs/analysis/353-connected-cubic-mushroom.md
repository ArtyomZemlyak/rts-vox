# Цельный кубический ядерный гриб

20.10.2026. Запрос — доработать стилистику самого гриба, сохранив
кубический реализм и ограниченную стоимость представления.

Прежние независимые эллипсоидальные клубы образовывали повторяющиеся
кольца, пересечения прозрачных граней и отдельные светящиеся бусины.
Новый силуэт объединяет основание, суженную колонну и широкую неровную
шляпку в одну ограниченную решётку. Растеризация объединяет пересечения,
меш содержит только наружные осевые грани. Размер ребра одинаков по XYZ.
Крупные перекаты на шляпке имеют разный размер, высоту и смещение; верх
светлее, нижние складки темнее, тепло постепенно остывает. Пылевая юбка
низкая, с неровным связанным фронтом вместо набора отдельных клубов.

Потолки: облако 49×57×49, пыль 57×7×57, прежние четыре события/26 секунд.
Внутренние занятые клетки не вычисляют цвет; повторная растеризация
занятой клетки пропускается. Пылевая высота вычисляется один раз на
колонку. Физика, свет вспышки, волна, урон и SIM не изменены.

## Проверки и стоимость

Артефакты: `out/nuclear-style-353/`. `mesh-probe.rs` непосредственно
подключает сохранённый прежний и текущий production-модули, использует
те же массивы MeshBuf и glam, release rustc. 60 измерений после двух
прогревочных, порядок before/after чередуется. Без параллельной сборки.

На раннем росте общая поверхность дороже на CPU примерно на 0,3–0,6 мс
для одного события. На пике плотного гриба треугольников меньше в3,1 раза,
сборка быстрее примерно на0,4 мс. Горячий слой на6с: 1824→816 треугольников,
45→7 мкс. Общая поверхность убирает скрытые пересекающиеся грани, но
не доказывает устранение всех задержек симуляции или прозрачного GPU fill.

Геометрические тесты проверяют отсутствие внутренних/дублирующих граней,
наружную ориентацию, конечность координат/цветов, диапазон alpha,
кубические нормали, широкий верх, высокую колонну и ограничение
90000 вершин на событие на13 стадиях роста/затухания.

Финальные release-проверки: 5 nuclear-тестов, 12 архитектурных, 3 проверки
документации; `fmt --check`, `check --workspace --all-targets --release`
