# Контакт двух движущихся машин и проверка брони фугасом

24.09.2026, ADR-384, P-54/P-50/P-58. Моторный контакт передавал другому
корпусу долю скорости догоняющей машины, не учитывая, что тот уже едет
в ту же сторону. Передача теперь использует скорость сближения вдоль
линии центров. У стоящей цели ответ прежний; у догоняемой уменьшается,
а при расхождении быстрее догоняющего не появляется. Фаза принятия
позиций и непроникновение корпусов не менялись. Проверка двух танков
в колонне сравнивает толчок стоящей и движущейся цели, проверяет
непересечение и точное продолжение после снимка. Математический тест
проверяет движение в одну сторону, навстречу и расхождение.
Скорости всех участников снимаются перед передачей толчков, поэтому
несколько контактов в одном тике не читают уже изменённую скорость;
в тики без контактов этот снимок не строится.

Это не завершает P-54: два танка, направленные друг на друга, сначала
получают встречные толчки без взаимного проникновения, но через 60
тиков перестановка слотов меняет итоговые позиции примерно на 20
клеток. Сквозной тест `head_on_driving_contact_is_slot_independent`
помечен `ignore` как точное воспроизведение дефекта; последовательное
принятие позиций требует отдельного парного решения для встречного
контакта. Контактного урона пока нет, как и длинной нативной серии
приземлений после взрыва. Эталонные хеши прошли, хеш 900 тиков боя 4×4
остался `b9c72d156327666e`.

Для калибровки фугаса `bench_shell_balance` теперь включает удар по
лобовой части танка и по корпусу шагохода, отдельно считает снятые
клетки сегментов и оставшиеся вмятины. В release на 240 тиках:

| Мишень и заряд | Снято клеток юнита | Из них сегментов | Вмятины сегментов | Жив |
| --- | ---: | ---: | ---: | --- |
| Лоб танка 0,5× | 153 | 0 | 22 | да |
| Лоб танка 1× | 338 | 36 | 77 | да |
| Лоб танка 2× | 630 | 36 | 0 | да |
| Лоб танка 4× | 1230 | 36 | 0 | да |
| Корпус шагохода 0,5× | 155 | 20 | 411 | да |
| Корпус шагохода 1× | 309 | 43 | 527 | да |
| Корпус шагохода 2× | 620 | 102 | 0 | да |
| Корпус шагохода 4× | 1256 | 238 | 0 | да |

Ноль вмятин при большом заряде не означает нетронутую броню: журнал
считает только ещё целые деформированные клетки; снятые перечислены
отдельно. Шагоход не является лёгкой машиной, поэтому испытание лёгкой
цели из P-50 по-прежнему открыто. Нативный исходный кадр одиночного
танка `out/armor-front-close` показывает, что фронтальные локальные
повреждения трудно различить с игровой камеры. Экспериментальные кадры
`out/armor-front-warm` и `out/armor-front-opposite` с более широкой
окраской не дали достаточно заметного
улучшения при дополнительной стоимости в боевом профиле и в код не
вошёл. P-58 остаётся открытым для отдельного решения о визуале брони.

Воспроизведение:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/cargo-local.ps1 run --release -p sim-core --bin bench_shell_balance
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/cargo-local.ps1 test -p sim-core a_convoy_contact_uses_its_closing_speed
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/cargo-local.ps1 test -p sim-core --test golden
```
