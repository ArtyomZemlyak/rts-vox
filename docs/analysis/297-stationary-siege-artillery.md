## Реализация и общие правила

ArtilleryTurretT3 — корпус 80×52×56 клеток по 150 мм (12×7.8×8.4 м),
один тяжёлый ствол, противооткатные направляющие, бронированный цоколь,
сенсор и боеукладка. Это настоящие размеченные воксели, не декорация:
ядро, оружие, связность, повреждение и отделение используют UnitBody.
Основание создаёт общий foundation; специального бетона сценария нет.

| Параметр | T3 |
|---|---|
| Оружие | Siege, один навесной фугас |
| Дальность | 2400 world units = 240 м |
| Перезарядка | 210 тиков = 7 с |
| Зарядка | 24 тика = 0.8 с |
| Скорость / множитель времени полёта | 400 world units/s / 1800 milli |
| Давление / материальная энергия | 40000 / 900 МДж |
| Доля тел / грунта | 360 / 540 МДж по общему правилу |
| Сетка волны | cell_units4, half_cells28; общие адаптация и потолки |

Темп/дальность/навесность: data/range-siege.ron. Заряд: siege-shell.ron.
T2 остаётся картечной. T3 не выпускает дополнительные кубики/снаряды
для имитации мощности. Она резервирует один слот общей очереди взрывов.
Числа не зависят от ручного управления, ИИ и имени сценария.

Наведение, движение цели, реальное дуло, возвышение, столкновения с
миром/телами/щитами, материальный бюджет и обрушение общие. Фундамент
может повреждаться: сильное попадание использует прочность бетона,
а не специальное правило «T3 всегда роняет турель».

В основной battle-world дописаны IDs60/61, по одной T3 на сторону.
Прежние IDs0..59 сохранены; всего62, по31. Площадки расчищены обычными
материальными блоками. Новый skirmish-siege — семь юнитов и два бетонных
укрепления, без нового кода урона/ИИ/опор. Меню «Осадная артиллерия T3»,
редактор «Осадная турель T3», native `--skirmish 5`, bench `--scenario siege`.
Обычный сценарий оставляет союзников игроку; --ai-vs-ai включает общий
контроллер обеим сторонам. CLI больше не требует именно world-battle
для этой возможности, достаточно любой боевой расстановки.

Коды типов дописаны: T3=9, Siege=7. Старые значения не переименованы.
Таблицы шаблонов/скинов/ghost/ригинга/повреждений получили T3; UI не
показывает стационарному орудию ходовую. Observation v3 имеет десять
дальностей; это структура наблюдения, не новый формат snapshot.
Новых полей snapshot/checkpoint нет. Кодек принимает новый enum-код,
включая запись отклонённой попытки сменить фиксированное оружие.
Снаряд и волна сохраняют тип заряда после повреждения установки.

## Ошибки, пойманные до доставки

- Первая разметка кольца перекрывала край 16³ ядра; seat_core отказал
  при создании модели. Ядро опущено до кольца, без обхода проверки.
- Независимый flood обнаружил три закрытых воздушных кармана (160 клеток)
  под поворотным узлом. Внутренний pack расширен, роли механизмов сохранены.
- Таблицы рендера были фиксированы на девяти шаблонах. Они расширены,
  основные массивы привязаны к COUNT.
- Второй выбор навесности при запуске учитывал только Canister. Оба
  этапа теперь используют общий loft, иначе T3 целилась бы по одной
  параболе и запускала по другой.
- Старый отсев попаданий ±8 м обрезал наклонённый крупный ствол. Общая
  безопасная граница выводится из размеров/масштаба тела; LocalMap
  хранит её transient. Точный voxel hit остаётся прежним.
- Native-кадры первого сценария показали T3 у обрезанных краёв стартового
  обзора. Расстановка уплотнена до дистанции75м между осадными орудиями;
  общая камера и дальность240м не изменены. Перепроверены placement,
  стрельба обеих T3 и запуск через HUD.
- Основная расстановка теперь оставляет два свободных места под лимитом64;
  тест трёх редакторских размещений явно использует уменьшенную fixture.

## Ограничения

Это новый контент и баланс боя, не оптимизация. Один тяжёлый снаряд
ограничивает число параллельных волн относительно картечного веера,
но его попадание обрабатывает более крупную область. Общие бюджеты
сохранены; время всей симуляции/FPS не объявляется улучшенным.
Секундные поздние фризы и B8 остаются отдельными открытыми задачами.
Для появления T3 нужен новый запуск расстановки: старый snapshot не
переписывает сохранённую армию. Числа дальности/заряда — начальный баланс,
а не утверждение о соответствии реальному артиллерийскому боеприпасу.
