# Неровные кучи после ядерного взрыва

20.10.2026, ADR-767.

## Воспроизведение

Нативный полигон640×192×640: ядерная шахта в100/16/100, база в410/16/330,
цель400/15/330, начало боя и900 тиков. Конфигурация взрыва из data/explosion.ron.
Снимок out/nuclear-rubble/after.snap содержит1857 фрагментов. Среди обычных
осевших фрагментов грунта487 имеют полную маску4³; бетон19, трава1.
При увеличении запаса материи такая куча сохраняет полную маску и размер.
Именно общий меш полной маски рисовал одинаковые кубики, заметные рядами.
Исходная картинка воспроизведена в out/nuclear-rubble/before/0004.png.

## Исправление и стоимость

Только рендер: полная неокрашенная куча земли/бетона/камня получает один из16
общих мешей по стабильному хешу ID. Меш состоит из трёх колотых блоков
и одной треугольной призмы. Неровные верхние плоскости и разные пропорции
сохраняют угловатый воксельный стиль. Поворот и оттенки входят в общий меш.
Итоговая коробка ±1,99 совпадает с прежним мешем и физикой фрагмента.

На кучу остаётся44 треугольника,132 вершины и одна сущность, без новых
физических объектов. Кэш ограничен16 вариантами для каждого из пяти
материалов. Дополнительный хеш считается при подготовке меша фрагмента;
спящие неизменённые фрагменты сохраняют существующий быстрый путь.
Форма не меняется при росте count или смене resting. Металл, краска,
секции тел и неполные маски остаются на прежнем точном построителе.

Количество материи, коллизии, расположение куч и их слияние не менялись.
Поэтому пространственное распределение куч остаётся свойством симуляции;
исправлен повторяющийся ровный куб, а не физика размещения. Сохранение
бюджета геометрии не является отдельным замером FPS.

## Проверки

- Release render blast, фильтр `fragments::`:18/18. Новые проверки покрывают все16
  различных вариантов:44 треугольника, точные границы, конечные нормали,
  отсутствие вырожденных граней, замкнутые рёбра с согласованным обходом.
- Выбор варианта ограничен и стабилен при изменении запаса/пробуждении;
  окрашенные, металлические и неполные фрагменты сохраняют прежний путь.
- Существующие проверки жизненного цикла, переиспользования сущностей,
  паузы, интерполяции и совпадения насыщенной кучи с физикой проходят.
- Нативное сравнение использует один снимок, камеру target, zoom1.5,
  окно1200×800 и пятый кадр после загрузки. Результат после исправления:
  out/nuclear-rubble/after/0004.png.
- На сравнении изображений ровные кубы заменены неровными кучами; большие
  части разрушенных зданий сохранили исходную форму. Остаточный рисунок
  распределения материи не маскируется смещением физики.
- Release-сборка игры и workspace/all-targets check успешны; архитектурные
  проверки12/12, связность документации3/3, fmt и diff check проходят.
