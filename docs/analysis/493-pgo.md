# 493 — PGO: headless-выигрыш, native отклонён

3 ноября 2026. Артефакты: `out/optimization-493/`.

## Причина и метод

Fat LTO (ADR-836) дал небольшой общий выигрыш. Следующий независимый эксперимент —
[profile-guided optimization](https://doc.rust-lang.org/rustc/profile-guided-optimization.html):
компилятор использует фактические ветвления и вызовы для inlining, раскладки кода и
register allocation. Исходная логика и настройки gameplay не меняются.

Для rustc 1.98.1 использован официальный LLVM 22.1.8 того же выпуска. Архив и его
SHA-256 взяты из `channel-rust-1.98.1.toml`; инструменты распакованы локально в
`out/optimization-493/toolchain`, глобальный toolchain не изменён.

`bench_battle` собран с `-Cprofile-generate` в отдельный target. Профиль собран на
World AI-vs-AI, 3000 тиков, physics8/navigation8/Rayon4, чтобы охватить позднюю
историю обломков. Первый запуск был остановлен внешним лимитом 20 минут и не дал
`.profraw`; повторный полный запуск без лимита завершился за 21 мин 46 с. Объём
merged profile — 5 045 984 байта. Затем release собран с `-Cprofile-use` и fat LTO.

## Детерминизм

- Instrumented 3000 тиков против обычной сборки: все 36 нетайминговых полей каждого
  тика совпали, endpoint hash `e1b57d109401f0e7`.
- PGO против fat LTO на 200 тиках: все 36 полей совпали.
- Две ordinary серии по 1600: все 36 полей каждого тика совпали.
- Replay snapshot300→600 на physics1/4/8: `695327e0588d053c` во всех режимах.

## Native A/B

Четыре 60-секундных capture AB/BA против fat-LTO ADR-836, Vulkan, 3840×2160,
Foreground+Maximized, saved tuning, navigation8/Rayon4. Все
`ValidForComparison=true`, `AcceptanceEligible=false`, поскольку 20 Гц нет.
Native PGO-сборка заняла 24 мин 42 с; executable вырос с 80 846 336 до
86 953 472 байта (+7,55%).

| Пара | Mean FPS | p99 кадра | `fragments` p50 | `simulation_core` p50 |
|---|---:|---:|---:|---:|
|1, PGO→fat|32,964→32,985|92,734→92,883 мс|3,079→3,235 мс|23,307→23,100 мс|
|2, fat→PGO|32,805→32,407 (−1,21%)|92,888→94,176 мс|3,562→3,512 мс|23,579→23,956 мс|

Сводно fat LTO → PGO: FPS 32,895→32,685 (**−0,64%**), p99 кадра
92,885→93,455 мс (**+0,61%**), `simulation_core` p50 **+1,25%**, realtime ratio
0,9103→0,9068 (**−0,39%**). `fragments` p50 улучшился на3,05%, но не перевешивает
общий результат.

## Решение

PGO **отклонён**. Headless-выигрыш не переносится в native FPS и темп симуляции.
Новый ADR, обязательный `.profdata` и изменение стандартного release не вводятся;
ADR-836 fat LTO сохранён. Артефакты оставлены для воспроизводимости отрицательного
результата. Следующий кандидат должен адресовать измеренную retained-history работу,
а не продолжать перебор build flags.
