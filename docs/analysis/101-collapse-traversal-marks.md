# Метки обхода при поиске опор

25.09.2026, ADR-408, P-45. База — `a980ae4`.

## Причина и изменение

При длинном проезде по километровому полигону поиск опор обходит до 379 654
компонент, из них 133 519 требуют проверки пути к заземлению. На каждом
проходе `resolve` создавал отдельный массив `seen` на все компоненты.

Теперь уже существующий буфер `component_roots` хранит временные метки
`u32::MAX` (ещё не посещён) и `u32::MAX - 1` (посещён). При завершении поиска
неподдержанная компонента получает прежний реальный номер корня; для
заземлённых компонент значение не читается. Метки инициализируются только
для кандидатов, а отдельный массив не создаётся. Порядок обхода,
результат обрушения и формат сохранения не изменились.

## Замер

Релизный CPU-стенд без рендера и GPU:

```powershell
.\target\release\bench_range.exe --range data/range-km.ron --move 2200,336 --ticks 6500
```

| Метрика | База (3 повтора) | После (2 повтора) |
| --- | ---: | ---: |
| p50 `collapse_resolve`, мс | 2,946–3,062 | 2,901–2,902 |
| p99 `collapse_resolve`, мс | 6,408–11,135 | 6,549–6,850 |
| p99 полного CPU-тика, мс | 9,592–12,765 | 9,609–9,748 |
| Снятые клетки | 128 349 | 128 349 |
| Круги патрулей | `0,5,1,5` | `0,5,1,5` |
| Итоговый хеш | `bb4a604c28e62856` | `bb4a604c28e62856` |

Медиана этой фазы стала меньше примерно на 2 %, но интервалы p99 полного
тика пересекаются. Показателя стабильных 120 FPS это не обеспечивает.
В 600-тиковом боевом опыте с одним энергетическим выстрелом получены те же
46 645 снятых клеток и хеш `c6373dfde61c255c`; p50 проверки опор
598 → 585 мкс, p99 полного тика 6,519 → 6,425 мс. Разница хвоста
мала для вывода об ускорении боя. Сырые журналы и бинарник базы находятся
в `out/backlog/adr-408`.

Перед этим проверены и отклонены уменьшение окна локального зонда с 96
до 64 и 32 клеток, кэширование коэффициента уклона и повторное
использование списка контактов: устойчивого выигрыша в одинаковом
6500-тиковом проезде они не дали. Замена умножения на знак сложением или
вычитанием смещения также не дала надёжного эффекта. Эти опыты не вошли
в код.

## Проверки

132 теста `voxel`, включая сравнение локального поиска с полным обходом,
тесты высоких номеров меток и повторного открытия графа после загрузки.
Прошли `cargo test --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`,
`cargo fmt --all --check` и релизная сборка нативного окна
`blast`. Контрольный `sim-cli --seed 42 --ticks 1000 --dump-hash`
сохранил хеш `12bd9cb0d53498f2`.
