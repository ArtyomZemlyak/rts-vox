# 597 — Шагоход: допуск движения по опорам и скачки корпуса (2026-11-14)

## Задача

Пользователь сообщил, что шагоход прыгает. Игровое название «Шагоход»
соответствует четырёхногому Strider; Walker04 называется «Волкер».
Основной воспроизведённый дефект — у Strider. Двуногие проверены на
регрессии. Исходный снимок вывернутых ног паука остаётся отдельным дефектом.
Контекст решений: свежие ревью 593–595; общий физический решатель опор
из этих ревью не объявляется реализованным.

## Изменение

- Профиль multiped сохраняет 50% опор вместо нуля. Для четырёх целых ног
  последняя пара должна быть диагональной. Очерёдность отрыва учитывает
  срок выхода за длину звеньев вместе с границами полосы ноги. Движение
  внутрь досягаемой области не считается немедленным выходом из неё.
- Прогноз приземления уточняется по оставшемуся времени полёта и проверяет
  одновременно полосу и длину звеньев, как фактический IK. Его дальность
  ограничена прежним максимальным ходом и при толчке с малой каденцией.
- До публикации принятого корпуса мотор проверяет ограниченное окно опоры.
  Он допускает часть запрошенного перемещения/поворота, пока ноги заканчивают
  шаг. Контактные альтернативы проходят ту же проверку. Ожидание опоры
  сохраняет маршрут и не считается столкновением.
- При ожидании прогноз шага сохраняет запрошенные направление и каденцию:
  посадка должна открыть следующий шаг корпуса. Использование только нулевого
  принятого смещения давало лишние шаги на месте и замедление после спуска.
- Прогноз опор и фактическая координация ног используют общий код. Отрываемая
  нога не опускает корпус перед собственным шагом. Для четырёх целых несущих
  ног с активным окном устранена повторная принудительная подгонка высоты:
  достижимость уже проверена мотором, высоту ведёт подвеска. На спуске старая
  подгонка после допуска давала дополнительный скачок вниз.

Окно применяется при min_support_pct >= 50, четырёх целых несущих ногах,
заземлённой подвеске и отсутствии импульса. Повреждённые/подброшенные корпуса
и другие схемы сохраняют подгонку высоты. Это ограниченная ветка допуска,
не общий балансировщик сил. Номинальная подвеска, размер кубика, заданная
скорость и предел 200 FPS сохранены. Корпус не меняется в отложенной фазе ног.
В новых расчётах используются Fx и стабильный порядок, без I/O/float в SIM.
