отчёт с методикой/ограничениями и ссылку из316. Старые результаты и

не является текущим эталоном — его задают тесты текущего кода.

## Правила работающей системы

Канон01–15 описывает систему и её контракты; `analysis/` содержит основания,
измерения, предложения и историю. Предложение в плане не становится правилом
до принятия и реализации. Реестр [ADR](12-decisions.md) и
[полные решения](analysis/10-decisions-full.md) имеют разные роли:
указатель и обоснование; это не две очереди задач.

| Область | Канон |
|---|---|
| Скоуп и архитектура | [01](01-concept.md), [02](02-architecture.md) |
| Детерминизм, snapshots и replay | [03](03-determinism.md) |
| Мир, разрушения, оружие и поля | [04](04-world.md), [05](05-units.md), [15](15-explosions-and-fields.md) |
| Движение, маршруты и видимость | [06](06-navigation.md) |
| Материя и экономика | [07](07-economy.md) |
| Генератор и моды | [08](08-worldgen.md), [09](09-modding.md) |
| GPU и сцены | [13](13-gpu.md), [14](14-demo-scenes.md) |

Перенос оставшихся механик экономики описан в [245](analysis/245-economy-port-plan.md);
проверка их производительности входит в OPT316-10. Продуктовые вопросы
сохраняются по месту в каноне, не дублируются отдельным списком блокеров.
