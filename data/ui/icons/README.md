# Laboratory UI icons

Lucide 0.468.0, https://github.com/lucide-icons/lucide/tree/0.468.0/icons.
34 original SVGs, 40×40 PNGs and embedded RGBA8 pixels are kept together.
Stroke colour is #dce9f5. Native UI displays icons at 19 logical pixels.
The upstream ISC license is in LICENSE; Feather-derived portions are MIT.
No font glyph or emoji is used as an editor tool icon.

Regenerate with `scripts/lab_ui_icons.py` (Pillow and resvg-py are optional
art tooling dependencies; the Rust game needs neither).
